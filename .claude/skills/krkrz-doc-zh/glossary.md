# 术语表（日 → 简中）

> 本表是 `doc/` → `doc/zh/` 翻译的**术语唯一基准**。翻译时先查本表；表里没有的术语，**先补充到本表（含理由）再使用**，不允许同词多译。

## 总则

1. **API 名称一律不译**。类名 / 方法名 / 属性名 / 事件名 / 常量名 / 枚举值 / 文件名 / 命令行参数 / storage 路径：保持原始 ASCII 写法（如 `Layer`、`loadImages`、`dfBoth`、`-repl`、`data/`）。
2. **类名对应的通用概念**用中文泛称时见表（例：类 `Layer` 保持原文；泛指"层"这个概念时用「图层」）。
3. **首次出现可括注英文**：`存储（Storages）`、`绘制设备（DrawDevice）`。同一节内不重复括注。
4. **代码块、行内代码原样**。包括注释（v1 硬规则，由 `scripts/check_pair.py` 强制）。
5. **专有名词保持**：吉里吉里Z（可首次括注 Kirikiri Z）、吉里吉里2、TJS2、KAG3、Wamsoft、krkrz、krkr2、Elements、REPL、Steam Deck、Vulkan / OpenGL / Emscripten / wasm 等。
6. **引用运行时的日文字符串 / 控制台输出**：保留原文，必要时在正文中补中文说明，不要直接改写引文。

## 文体与标点

- 简体中文技术文档体：客观、简洁，不用“……呢”“……哦”等口语收尾。
- 标点转换：`、` → `，`；`「」` → `“”`；`『』` → `‘’`；`〜` / `～` → `~`；`・`（并列）→ `、`。
- 中文与拉丁文/数字之间加一个半角空格（`使用 Layer 类`），全角数字改半角。
- 保留原文的信息层级（`注：` / `※` → `※` 或 `注意：`），不新增原文没有的强调（不擅自加粗）。
- 中助词省略与时态（〜します/〜です）自然转为中文陈述句，不逐字直译。

1. 在表中新增一行：`| 日文 | 中文 | 备注（首次出现位置 / 选择的理由） |`。
