# 文件/文件夹一览

## 文件/文件夹一览

这里说明与吉里吉里相关的文件与文件夹。

并非网罗所有文件。主要以需要特别注意的文件为中心。关于吉里吉里Z SDK 发布归档的文件夹结构，请参阅 readme.txt。

## 文件夹

- ****plugin** 与 **plugin64****  
  吉里吉里查找插件所用的文件夹。吉里吉里在自身可执行文件所在文件夹中存在这个文件夹时，会参照其中放置的插件。使用 `plugin64` 的只有 Windows 的 64bit 版，Linux 等在 64bit 版下也是 `plugin` ([插件文件夹的名称](Plugins.md#plugin-folder))。→
- ****data** 与 **content-data****  
  吉里吉里可执行文件所在文件夹中存在这个文件夹时，将该文件夹视为项目文件夹并执行。→

## 文件

- ***.**xp3****  
  吉里吉里用的归档文件。→
- ****data.xp3** 与 **data.exe****  
  该文件与吉里吉里的可执行文件位于相同文件夹时，吉里吉里会将其视为项目文件夹并执行。→
- ***.**tpm****  
  吉里吉里用的插件，启动时自动读取的文件。→
- ****krdevui.dll****  
  吉里吉里的开发用工具共同使用的 DLL。不需要将此文件随附到面向最终用户的发布物中。
- ****krmovie (视频播放机制)****  
  视频播放机制在当前吉里吉里Z 中已整合到本体可执行文件中，不需要另行随附 `krmovie.dll` (播放 WebM/MP4/WMV/MPEG-1 等无需追加 DLL)。→ [VideoOverlay 类](../reference/VideoOverlay.md)
- ***.**dll****  
  如果是吉里吉里用的插件，则必须随附到面向最终用户的发布物中。当然，不需要的插件无需随附。→
- ***.**so** (Linux 版)**  
  Linux 版的插件 (`plugin/` 内) 与随附库 (可执行文件旁边的 `libSDL3.so.0` 等)。可执行文件与插件中嵌入了 `$ORIGIN` 的 RPATH，因此无需设置 `LD_LIBRARY_PATH` 也会读取随附版。 → [Linux 版的发布包](../topics/core/linux_package.md)
- ****krkr.eXe****  
  吉里吉里本体。分发给最终用户时可以更改文件名。
- ***.**cf** 与 *.**cfu****  
  记述了针对吉里吉里本体的选项的文件。要使通过“吉里吉里设置”(-userconf) 指示给吉里吉里本体的选项 (其中包含 -datapath 选项的指定等) 生效，必须也将该文件随附到面向最终用户的发布物中。→
  Linux 版的发布物中，将决定存档数据位置 (`~/.local/share/<orgname>/<appname>/`) 的 `orgname` / `appname` 写入 `<exe名>.cf` 并随附 ([Linux 版的发布包](../topics/core/linux_package.md) 的 krkrz_linux 会自动生成)。
- ****ファイル破損チェックツール.exe** 及其 .**ini** 文件**  
  文件损坏检查工具。分发给最终用户时可以更改文件名，但此时必须将 .exe 文件与 .ini 文件的名称改为相同名称。吉里吉里Z SDK 发布时它位于 enduser-tools 内，但分发给最终用户时，通常需要放置到吉里吉里的可执行文件所在文件夹中。→
- ****startup.tjs****  
  TJS 脚本文件。吉里吉里会查找项目文件夹正下方的这个文件，并最先执行。→
- ***.**tjs****  
  TJS 脚本文件。
- ****msgmap.tjs****  
  消息映射文件。如果印象中没有创建过它，就不需要将此文件随附到面向最终用户的发布物中。→
- ***.**sig****  
  密钥、签名工具输出的签名文件。文件损坏检查工具等会参照它。→
- ***.**rpf****  
  Releaser 的配置文件。记录了 Releaser 的设置信息。此文件不需要随附到面向最终用户的发布物中 (Releaser 会自动排除此文件)。→
- ****hwexcept.log****  
  吉里吉里本体崩溃时，可能会在 -datapath 选项指定的位置创建。虽说崩溃也有各种情况，但如果创建了这个文件，那就是相当严重的崩溃，请从最终用户处回收，必要时发送给吉里吉里的作者。此文件不需要随附到面向最终用户的发布物中。
- ***.**console.log****  
  吉里吉里的控制台日志文件。通常在吉里吉里崩溃等情况下，可能会在 -datapath 选项指定的位置创建。此文件记录的日志大多数情况下是由脚本的记述错误导致的。在应用程序开发过程中，或者分发给最终用户之后，请从最终用户处回收，用于调试。此文件不需要随附到面向最终用户的发布物中。
- ***.**dump.txt****  
  TJS 的转储文件。此文件不需要随附到面向最终用户的发布物中。→
- ***.**sli****  
  循环调谐器输出的循环定义文件。→
- ***.**tft****  
  已渲染字体数据生成工具输出的已渲染字体数据。→
- ***.png *.jpeg *.jpg *.tlg *.bmp**  
  图像文件。→
- ***.wav *.tcw *.ogg *.opus**  
  音频文件。→
- ***.wmv *.mpg *.mp4 *.ogv**  
  视频文件。→ [VideoOverlay 类](../reference/VideoOverlay.md)
