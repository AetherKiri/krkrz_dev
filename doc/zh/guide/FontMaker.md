# 预渲染字体数据创建工具

## 关于预渲染字体数据创建工具

预渲染字体数据创建工具是用于创建**预渲染字体**数据的工具。可以通过 [Font.mapPrerenderedFont](../reference/Font.md#mapprerenderedfont) 将其分配给实际的字体。

所谓预渲染，就是预先将字体渲染好 ( 在此是指展开 TrueType 轮廓字体并转换为位图字体 ) 的意思。如果不使用它，吉里吉里会按需在运行时进行渲染。

预渲染字体在制作者一侧的环境中创建，因此使用这种字体，就可以不受玩家一侧环境的影响而使用相同的字体。

预渲染字体的数据是位图字体数据。也就是说，它不是像 TrueType 那样可缩放 ( 可自由改变大小 ) 的字体，因此一个字体文件只能处理一种固定大小的字体。

> **Note:**
> 如果要创建预渲染字体数据的原始字体的作者，是否允许以这种用途 ( 将根据该字体创建的众多字符位图数据与游戏等一起分发，并组合这些位图数据用于文字显示 ) 使用该字体尚不明确，建议向该字体的作者确认。
>
> 顺带一提，这种预渲染字体文件是吉里吉里独有的格式，几乎没有转用于其他用途的可能。
>
> 吉里吉里的作者对使用本软件所产生的任何问题概不负责。

本工具强烈依赖 OS 的 UNICODE 支持，因此在 Windows 95 上无法运行。在 Windows 98/98SE/ME 以及 Windows NT 4.0 上可以运行，但部分功能受到限制。如果是 Windows 2000/XP，则可以使用所有功能。

当然，受 OS 种类限制的只是创建这种字体的环境，与使用本工具创建的预渲染字体数据的一方的 OS 种类无关。

## 预渲染字体数据创建工具的使用方法

![](../_assets/FontMaker.png)


运行预渲染字体数据创建工具 ( tools 文件夹中的 krkrfont.exe ) 后，会显示上面的画面。

- **“字体名”**  
  指定作为创建预渲染字体数据来源的字体名。如果要创建竖排用字体，请选择开头带 @ 标记的字体。
- **“显示所有 TrueType 字体”**  
  不勾选时，“字体名”中只列出字符种类为日文的字体，勾选时则显示所有 TrueType 字体。
- **“尺寸(字符高度)”**  
  以像素为单位指定要创建的预渲染字体的尺寸 ( 字符的高度 )。
- **“抗锯齿”**  
  指定是否进行抗锯齿处理。进行抗锯齿处理后字体会变得平滑。
- **“粗体”**  
  指定是否设为粗体。只能在 Windows NT 系列 OS ( NT4, 2000, XP, Vista, 7 等 ) 上勾选。
- **“包含字体内的所有字符”**  
  指定是否包含字体中存在的所有字符。只能在 Windows NT 系列 OS ( 但 NT4 除外 ) 上勾选。
  
  勾选后，将输出字体中包含的所有字符。
  
  不勾选时，只输出与 Shift JIS 相应的字符以及半角英文数字/假名。
  
  > **Note:**
  > 不勾选时的运行情况取决于本工具运行所在的区域设置。通常，在日文版 Windows 上运行时，意味着只输出与 Shift JIS 相应的字符等。( 话虽如此，作者没有日文版 Windows 以外的环境，所以并不清楚 )
- **“包含专用字符”**  
  指定是否包含专用字符。只能在 Windows NT 系列 OS ( 但 NT4 除外 ) 上选择。在其他 OS 上则始终为勾选状态。
  
  专用字符可以使用 Windows 附带的“专用字符编辑程序”等创建。
- **“示例”**  
  显示按所选条件创建的预渲染字体的示例。在此“示例”中，可以确认要输出的所有字符。
- **“输出文件”**  
  指定要输出的文件。要输出的文件的扩展名是 .tft。点击“浏览”可以通过对话框指定文件。
- **“创建”**  
  创建预渲染字体文件。
- **“关闭”**  
  退出本工具。
