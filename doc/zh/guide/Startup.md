# 启动方法

## 关于吉里吉里的启动

要启动吉里吉里并指定脚本，通常需要先确定**项目文件夹** (

请参照)。

确定项目文件夹的方法有几种，但按下述顺序优先 (上面写的方法只要适用就会被采用)。

关于启动时传递给吉里吉里的选项，

请参照。

## 项目文件夹的确定顺序

- **在命令行指定的文件夹或归档**  
  当作为命令行参数指定了文件夹时，将其视为项目文件夹并执行。
  
  当作为命令行参数指定了 XP3 归档时，视为其中包含项目文件夹并执行。
  
  从命令提示符也可以将文件或文件夹指定为命令行参数，但最简单的方法是使用资源管理器或“打开”，把项目文件夹或文件拖放到吉里吉里可执行文件的图标上。
  
  另外，在桌面等位置放置一个把特定项目文件夹写为吉里吉里可执行文件参数的快捷方式会很方便。
- **可执行文件同位置的 content-data 文件夹**  
  如果可执行文件同位置存在名为 "content-data" 的文件夹，则将其视为项目文件夹并执行。
- **可执行文件同位置的 "data.xp3" 文件**  
  如果可执行文件同位置存在名为 data.xp3 的归档文件，则将其作为 XP3 归档格式，视为其中包含项目文件夹并执行。
- **可执行文件同位置的 data 文件夹**  
  如果可执行文件同位置存在名为 "data" 的文件夹，则将其视为项目文件夹并执行。

用任何一种方法都无法确定时，会出现文件夹/归档选择画面。

不过，如果在发布选项中指定了“仅从 XP3 归档执行”，则只会执行 data.xp3 文件、data.exe 文件以及“XP3 归档附加在自身上时”的情形 (

请参照)。

## 文件夹/归档选择

文件夹/归档选择画面如下所示。

- **“OK”按钮**  
  开始执行当前选中的文件夹或文件。
- **“取消”按钮**  
  不执行任何操作并退出吉里吉里。

## 最先执行的文件

项目文件夹确定后，最先执行的是项目文件夹内的 startup.tjs。如果没有它则会出错。

最先执行的文件也可以用 -startup 指定。

请参照。

## 消息映射文件

吉里吉里会在启动后立即检查吉里吉里相同文件夹中是否存在 msgmap.tjs，如果存在则执行。但在发布选项中指定不读取它时除外 (

请参照)。在 msgmap.tjs 中，可以使用 [System.assignMessage](../reference/System.md#assignmessage) 更改消息的分配。msgmap.tjs 也可以

创建。
