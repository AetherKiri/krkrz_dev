# Releaser

## 关于 Releaser

Releaser 是用于将文件夹打包为归档文件的工具。

此外，还可以指定吉里吉里的项目文件夹，创建一个内部包含该项目文件夹的单个可执行文件。

## Releaser 的使用方法

![](../_assets/ReleaserSelect.png)


执行 Releaser ( tools 文件夹中的 krkrrel.exe ) 后，首先会要求指定文件夹，请指定文件夹。

此处指定的文件夹中的文件将成为处理对象。

> **Note:**
> Releaser 具有这样的功能：在创建最终归档的过程中，如果发现内容完全相同的文件，即使文件名不同也会将它们合并为一，只使用一个文件的容量。

> **Note:**
> Releaser 会自动忽略 CVS 元信息目录 (名为 "CVS"，其中存在名为 "Repository" 的文件的目录)。此外，还会忽略名称以 . (点) 开头的文件和目录 (UNIX 风格的隐藏文件、Subversion 元信息目录等)。

> **Note:**
> Releaser 创建归档后，会在创建归档的目录中创建 **default.rpf** 文件。其中记述了创建归档时的选项，下次创建归档时可以方便地以相同设置创建。

## Releaser 的设置画面

选择文件夹后进入设置画面。

- **“返回文件夹选择”按钮**  
  可以重新进行文件夹选择。
- **“配置文件：保存”按钮**  
  将当前设置保存到文件。
- **“配置文件：读取”按钮**  
  从文件读取设置。
- **“创建”按钮**  
  基于当前设置，输出归档文件或 EXE 形式的可执行文件。
- **“取消”(或退出) 按钮**  
  退出 Releaser。
- **“输出”标签页**  
  ![](../_assets/ReleaserOutput.png)
  
  - **“输出格式”**  
    选择“.XP3 归档”时，输出 xp3 格式 ( 吉里吉里标准的归档格式 ) 的文件。选择“.EXE 形式可执行文件”时，输出可执行文件。选择“.EXE 形式可执行文件”时，将使用放置在 Releaser ( krkrrel.exe ) 同一文件夹或其上级文件夹中的 krkr.eXe。
  - **“输出文件”**  
    请指定要输出的文件。点击“浏览”按钮即可在对话框中指定文件。
- **“文件”标签页**  
  ![](../_assets/ReleaserFiles.png)
  
  
  可以按扩展名分别选择“要压缩的文件”“包含在归档中但不压缩的文件”“不包含在归档中的文件”。通常保持默认分类即可。
  
  将文件归类为“要压缩的文件”后会进行压缩，因此文件大小会变小。而且，即使使用文本编辑器或二进制编辑器查看内容，也无法轻易解读。但是，压缩也有解压时耗时的缺点。PNG、JPEG、ERI 等本身已经被压缩，即使归类为“要压缩”效果也很小，还会使解压花费更多时间，因此不建议进行压缩。
- **“选项”标签页**  
  ![](../_assets/ReleaserSettings.png)
  
  - **“不压缩大文件”**  
    此设置表示：即使相应文件被归类为“要压缩的文件”，只要达到指定大小以上就不进行压缩。由于吉里吉里的结构，被压缩的文件必须解压到内存中，因此压缩大文件会使运行时的开销变高。
  - **“解压保护”**  
    勾选后，会为归档内部的索引 ( 所存储文件的列表 ) 添加“解压保护”属性。由此可以向归档解压工具表明“作者不希望文件被解压”的意愿。
  - **“OggVorbis 码本共享”**  
    勾选后，将共享 OggVorbis 文件 ( .ogg 文件 ) 的矢量量化用码本。OggVorbis 文件在许多情况下会在多个文件之间各自持有相同的码本，因此将它们合并为一可以节省体积。
  - **“压缩索引”**  
    勾选后，会压缩归档内部的索引 ( 所存储文件的列表 )，从而节省体积。
  
  > **Note:**
  > 即使勾选“选项”标签页中的“解压保护”，也**并不是真的会进行加密以使文件无法解压**。只是能够表明意愿而已。另外，制作归档解压工具的人 ( 如果有的话 ) 请考虑此解压保护标志的存在 ( 例如在该标志已置位时拒绝解压，或在解压前发出警告等 )。
- **“可执行文件设置”标签页**  
  仅在输出格式指定为可执行文件时显示。
  
  此设置画面与
  
  相同。
  
  
  
  ![](../_assets/ReleaserExeSettings.png)
  
  - **“选项”**  
    可以设置可执行文件的默认选项。
  - **“图标”**  
    可以指定可执行文件的图标。

## 命令行选项

Releaser 接受以下命令行选项。

- **文件夹名**  
  指定目标文件夹。
- **-**go****  
  立即创建归档并直接退出。请在批处理等场景中使用。选项等请预先以 default.rpf 为名保存在目标文件夹中 (即使没有它，与 -nowriterpf -out 选项组合也可以创建归档)。
- **-nowriterpf**  
  退出时不写出 default.rpf。
- **-out 文件名**  
  指定输出文件名。
- **-rpf 文件名**  
  指定要读取的配置文件。

例如，按如下方式指定。

```
krkrrel project -out ..\release\data.xp3 -nowriterpf -go
```
