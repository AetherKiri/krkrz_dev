# 吉里吉里设置

## 关于吉里吉里设置

“吉里吉里设置”是一个可以用 GUI 设置吉里吉里选项的工具。

它存在的目的是让最终用户 (二次用户) 能够自行进行一定程度的故障排查和性能调整。

引擎设置通过在吉里吉里可执行文件本体上附加 -userconf 来启动。



选项的名称、可设置的值以及选项的说明使用吉里吉里引擎本体内置的信息。说明的语言跟随 OS 的语言设置 ( ja / en / chs / cht )，也可以用启动选项 [-language](CommandLine.md) 显式指定。

## 关于配置文件

吉里吉里的配置文件有 2 种。一种是与吉里吉里可执行文件放置在同一位置、将可执行文件名的扩展名改为 **cf** 的文件，另一种是放置在

的 -datapath 所指定的数据保存位置、将可执行文件名的扩展名改为 **cfu** 的文件，共两种。

cfu 由面向最终用户的“引擎设置 (-userconf)”生成。

使用 Releaser 进行设置时会创建 .cf 文件，但请注意，该文件如果不与吉里吉里引擎本体一起分发，所设置的选项就不会生效。

这些文件如果不存在，则会在启动引擎设置并按下 OK 按钮时创建。

> **Note:**
> 配置文件内部，每一行都排列着“名称="值"”这样的记述。“值”部分由连续的 \xNN 构成，每一个都是 UNICODE 中的码位值。例如记述为 opt="\x61\x62\x63\x3042\x3044\x3046" 时，它表示“abcあいう”。从其他应用程序等向这些文件写入时请注意。
>
> 另外，像 opt="abcあいう" 这样不使用 \xNN 形式来记述时，吉里吉里引擎本体能够正确识别它，但引擎设置无法识别这种形式，有可能不会按预期运行。值两侧的双引号也是必需的。
