# 密钥与签名工具

## 关于密钥与签名工具

密钥与签名工具是一个用于对要发布的数据进行简单**电子签名**的工具。

使用电子签名，可以检查文件是否由正当的制作者创建、文件是否被篡改、文件是否损坏。

目前，

会使用此签名。

## 关于公钥与私钥

要使用密钥与签名工具，需要用此工具创建“**公钥**”(public key) 和“**私钥**”(private key) 这两个成对的(配对的)密钥(**密钥对**)。

虽说称为密钥，其实体是如下形式的字符串。

```
-----BEGIN PUBLIC KEY-----
MIGJAoGBAJYfPysW57qE3J2ddGWEG+RzXUzFkWa0ct3p7qJfuWDB+52DbfS9qSpw
iTHQ54vl7K35x+WDQdn29cfgJxp9UD3fzY4h6E2ReE9vj4h0FCMK8dpCFnQkOD/M
hDSiXfXz7KmfMXppM0CjofvH+IL7BJ3/GcLFcuEw3hEnzoajIm1TAgMBAAE=
-----END PUBLIC KEY-----
```

公钥是可以公开的密钥，私钥是不得公开的密钥。

进行签名时使用私钥。电子签名是使用该私钥生成的。

验证该签名时使用公钥。私钥与公钥总是成对存在，只有使用相应私钥进行的签名，才能用与该私钥成对的公钥正常验证。

即使不知道私钥的人用其他私钥进行签名，也无法用正当的公钥验证该签名。从公钥推测私钥是不可能的，因此只有持有私钥的人才能生成正当的签名。

> **Note:**
> 本来，在公开“公钥”时，需要让人确认该“公钥”是否为正当之物。如果连公钥本身是否正当都无法判断，电子签名的意义就会变得淡薄。但是，吉里吉里的密钥与签名工具并没有考虑到这一步。

> **Note:**
> 吉里吉里的密钥与签名工具所使用的加密方式在 2.25beta7 中从 ECC(椭圆曲线加密)更改为 RSA。
>
> 吉里吉里的密钥与签名工具生成的 RSA 密钥长度为 1024 位。另外，私钥不进行口令保护。
>
> 吉里吉里的密钥与签名工具生成的 RSA 公钥与私钥与其他软件的 PEM 格式密钥具有兼容性，但使用密钥与签名工具以外生成的密钥，或将密钥与签名工具生成的密钥用于其他软件时，其运行不受支持。

## **密钥生成**的方法

启动密钥与签名工具(tools 文件夹中的 krkrsign.exe)后，最先显示的是密钥生成画面。

![](../_assets/sign0.png)

- **“生成”按钮**  
  点击后即开始生成密钥对。首先会出现一个“正在收集熵”的窗口，并要求您随意移动鼠标，请按指示操作(这是为了生成不会被他人推测出的密钥)。
  
  窗口关闭后，下方的“生成的公钥”和“生成的私钥”栏中会显示生成的密钥对。
- **生成的公钥**  
  显示生成的公钥。按下旁边的“复制”按钮，即可将密钥复制到剪贴板。
- **生成的私钥**  
  显示生成的私钥。按下旁边的“复制”按钮，即可将密钥复制到剪贴板。
  
  出于安全考虑，关闭此窗口时剪贴板的内容会被清除，请注意。

## **签名**的方法

点击“签名”标签页后，会显示签名画面。

![](../_assets/sign1.png)

- **私钥**  
  请指定私钥。
- **目标文件**  
  可以指定要签名的目标文件。
  
  按下“浏览”按钮后会打开文件浏览对话框，请指定目标文件。
  
  也可以将目标文件拖放到此窗口来指定目标文件(当前版本无法一次对多个文件进行签名)。
- **“签名”按钮**  
  对目标文件进行签名。
  
  签名文件为在目标文件的文件名后附加扩展名 .sig 的文件名，但作为例外，吉里吉里本体 (exe) 的情况下，签名会被嵌入本体中。

## **签名验证**的方法

点击“签名验证”标签页后，会显示签名画面。

![](../_assets/sign2.png)

- **公钥**  
  请指定公钥。
- **目标文件**  
  可以指定要验证签名的目标文件。
  
  按下“浏览”按钮后会打开文件浏览对话框，请指定目标文件。
  
  也可以将目标文件拖放到此窗口来指定目标文件(当前版本中，无法用此工具一次验证多个文件的签名)。
- **“检查”按钮**  
  验证目标文件的签名。
  
  结果会通过消息框通知。

## 从命令行使用的方法

通过从命令行使用密钥与签名工具，可以对文件进行签名。这在与 make 等工具组合使用时很方便。

按以下格式指定。

```
krkrsign -sign "対象ファイル名" "秘密鍵ファイル名"
```

私钥文件名请指定以文本形式保存了私钥的文件。

例如，要对 game.eXe 进行签名时

```
krkrsign -sign "game.eXe" "key.priv"
```

这样指定。一次调用只能对一个文件进行签名。
