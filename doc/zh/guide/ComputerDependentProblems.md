# 关于环境相关故障

## 环境相关故障

这是由最终用户 (二次用户) 环境的故障引起的吉里吉里故障及其对策。

在制作吉里吉里时，我们尽力避免出现环境相关的故障，但计算机的设置和构成非常多样，因此环境相关的故障终究还是会发生。

有些情况可以通过针对个别症状的处理来应对，但总体上请采取以下对策。

- 请将驱动程序更新为最新且稳定的版本
- 请停用常驻程序 (特别是杀毒软件、内存清理类软件、窗口外观修改类软件、Windows 兼容 shell 等容易与其他软件发生冲突的程序)
- 请使用各种检查工具 (“磁盘检查” (OS 标准的磁盘检查工具)、[memtest86](http://www.memtest86.com/) 等) 检查计算机
- 请检查 HDD 的剩余容量是否充足
- 请参照 [WinFAQ](http://homepage2.nifty.com/winfaq/) (おだ 氏的页面) 等，查找是否出现了类似的症状，并据此进行应对
- 请先以安全模式启动一次，然后再重新以普通模式启动
- 使用 CPU 加速器时，CPU 的特定功能可能存在限制，因此请仔细阅读 CPU 加速器的说明书，根据情况可能需要在引擎设置中禁用个别的 CPU 功能 (例: [http://buffalo.melcoinc.co.jp/qa/cpu/b4590010.html](http://buffalo.melcoinc.co.jp/qa/cpu/b4590010.html) 的情况下，请禁用 SSE)
- 请重新安装 OS

可以针对吉里吉里引擎设置的选项，几乎都是为了处理环境相关的故障而存在的。

也请参照。

## 环境相关的症状

下面提到的“引擎设置”是指面向最终用户的设置工具 (引擎设置.exe)。

- **安装的数据已损坏**  
  症状包括出现“読み込みエラーが発生しました”等读取错误类错误、“作品运行中死机”、“出现 EAccessViolation 错误”，以及其他不可预测的运行表现。
  
  由于安装的数据可能已损坏，请使用“文件损坏检查工具”等确认安装的数据是否损坏。
- **画面切换时或跳过时死机**  
  在画面切换 (转场时) 或高速跳过等画面绘制频繁发生的场景中死机时，显示驱动程序可能存在问题。
  
  请确认显示驱动程序的版本是否为最新且稳定的版本，如果较旧，请更改为最新且稳定的版本。
  
  或者，在“引擎设置”中更改“双缓冲方式”或“垂直同步等待”的设置可能会有所改善。
  
  如果正在使用 nVIDIA 显卡附带的实用工具“nView Desktop Manager”，请卸载或禁用此工具。
- **画面绘制异常缓慢**  
  特别是在全屏时吉里吉里放大显示图像的情况下，或显式启用了双缓冲的情况下，如果画面绘制异常缓慢，在“引擎设置”中更改“双缓冲方式”或“垂直同步等待”的设置可能会有所改善。
  
  此外，如果不是在显示器侧而是在引擎侧进行放大，性能可能会随着放大而下降。这种情况下，在引擎设置中将“全屏时的画面分辨率”设为“最接近的分辨率”，放大就会改由显示器侧进行，但根据显示器的不同，可能无法以正确的宽高比显示图像。
- **画面一直全黑，或者图像紊乱**  
  特别是在全屏时吉里吉里放大显示图像的情况下等，如果画面一直全黑，或者图像紊乱，或者死机，在“引擎设置”中更改“双缓冲方式”或“垂直同步等待”的设置可能会有所改善。
- **视频播放失败**  
  使用覆盖层进行视频播放失败 (显示错误、死机) 时，或者视频播放刚结束就死机时，禁用硬件加速可能会有所改善。请在“显示属性” (在桌面上单击右键，在弹出的上下文菜单中选择“属性”后显示的对话框) 的“设置”标签页中，按下“高级”按钮后显示的对话框的“疑难解答”标签页里，将“硬件加速”的滑块从最大开始依次向“无”的方向移动，进行尝试。
  
  也建议在脚本侧设置不进行视频播放。
  
  或者，在“引擎设置”中更改“双缓冲方式”或“垂直同步等待”的设置可能会有所改善。
- **声音断续、无声，或声音播放中死机**  
  根据声卡和环境的不同，会出现播放断断续续、混入噪声、从途中开始听不到声音等情况。根据情况，还会出现仅在声音播放中死机等症状。
  
  如果这种问题发生在转场 (画面切换) 或较重的特效过程中，在引擎设置中将“系统整体-低优先级”设为“启用”，或将“系统整体-CPU 使用率降低”设为“启用”，可能会有所改善。
  
  (吉里吉里Z 的声音输出使用 miniaudio (WASAPI 共享模式)。旧的 DirectSound 特有的设置已被移除。)
- **无法顺利操作**  
  如果鼠标移动辅助或鼠标手势实现工具等软件常驻，可能会出现无法操作作品的情况。请解除此类软件的常驻。
  
  如果导入了第三方 (非 OS 标准) 的鼠标驱动程序，可能会在操作方面产生故障。这种情况下，请禁用或卸载第三方驱动程序，使用 OS 标准的驱动程序。
  
  在支持手柄的软件中，如果连接着手柄 (摇杆)，可能会因手柄的故障而无法操作作品。请确认是否因为手柄上放着东西而导致手柄按键处于被按下的状态。
  
  此外，有些环境在未连接手柄 (摇杆) 时，会将手柄按键误检测为被按下的状态。这种情况下，请禁用手柄的驱动程序。
  
  由于手柄或摇杆的轴的中心调整不充分，可能会出现操作故障。这种情况下，请从控制面板的“游戏控制器”中进行游戏控制器的调整。
  
  实在无法禁用手柄驱动程序时，可以在吉里吉里侧设置为不使用手柄。请在引擎设置中将“是否使用手柄”设为“不使用”。
  
  使用第三方鼠标驱动程序时，可能无法通过滚轮进行输入。这种情况下，在引擎设置中将“鼠标滚轮旋转检测方法”设为“窗口消息”，可能会有所改善。
- **频繁发生抖动**  
  有时会因内存不足而频繁发生抖动 (大量的换入、换出)。
  
  在引擎设置中将“系统整体-内存使用量”设为“低”，可能会有所改善。
  
  但是，这会降低性能，因此也可以不更改“系统整体-内存使用量”选项，而是将“图形-图像缓存限制”设为“4MB”或“8MB”等比较低的值，这样有可能在不太降低性能的情况下减少内存使用量。
