# 关于转场

## 什么是转场

转场是一种花费时间进行画面切换的效果。吉里吉里Z 的转场既可以针对单个图层进行，也可以针对图层树进行。

如果给图层指定了切换源，则两个图层会进行切换。

前者的情况下，对应的图层会整体切换；后者的情况下，图层的树结构会原封不动地整体切换。

请参照 [Layer.beginTransition](../reference/Layer.md#begintransition) 方法。



吉里吉里Z 通过称为“**转场处理器**”的对象来管理转场。这些是在 Layer.beginTransition 方法的 name 参数中指定的对象，当前版本中吉里吉里本体内置了 3 个。也可以通过插件进行扩展。



下面说明吉里吉里本体内置的转场处理器，以及通过扩展转场插件 ( extrans.dll / extNagano.dll ) 变得可用的转场处理器。

## 选项的指定

- **从 TJS2 使用的情况**  
  Layer.beginTransition 方法的 options 参数中，以字典数组的形式指定。例如，要以 vague=100 time=2000 rule=rule1.png 指定 "universal" 转场时，像下面这样指定 options 参数。
  
  
  
  `%[vague:100, time:2000, rule:"rule1.png"]`

## 内置转场处理器

吉里吉里本体内置了以下 3 个转场处理器。

- ****crossfade****  
  "crossfade" 转场 (交叉淡化转场) 是最简单的转场，进行单纯的交叉淡化。
  
  选项如下。
  
  - **time (必需)**  
    以毫秒为单位指定进行转场的时间。
- ****universal****  
  "universal" 转场 (通用转场) 是根据称为 rule 图像的灰度图像进行转场的效果。rule 图像通过 rule 选项指定，图像中越暗的地方越早切换到切换源。
  
  如果 rule 图像比要进行转场的画面小，则会以平铺方式铺满；如果比要进行转场的画面大，则只使用左上部分。
  
  选项如下。
  
  - **time (必需)**  
    以毫秒为单位指定进行转场的时间。
  - **rule (必需)**  
    指定 rule 图像的文件名。rule 图像必须是 256 阶灰度的图像。指定其他图像时会被强制转换为灰度。
  - **vague**  
    指定“模糊区域值”。指定较小的值 (如 0) 时，画面的切换前部分与切换后部分之间的边界会变得清晰。指定较大的值 (如 128) 时，该边界会变得模糊、平滑。根据 rule 图像的不同存在最优值。省略时视为指定了 64。
- ****scroll****  
  "scroll" 转场 (滚动转场) 是让切换源或切换目标中的一方或双方滑动，从而产生滚动效果的转场。
  
  选项如下。
  
  - **time (必需)**  
    以毫秒为单位指定进行转场的时间。
  - **from**  
    指定切换源的图层从哪个方向出现。
    
    sttLeft 为从左侧 (默认)、sttTop 为从上侧、sttRight 为从右侧、sttBottom 为从下侧出现。
  - **stay**  
    指定切换源和切换目标的图像如何运动。
    
    ststNoStay 时，切换目标的图像会被切换源的图像推着移出 (默认)。可以产生两个画面相连着滚动的效果。ststStaySrc 时，切换目标的图像会移动并移出，切换源的图像从其背后出现。ststStayDest 时，切换目标的图像保持静止，切换源的图像进入其中。

## 扩展转场插件

扩展转场插件 ( extrans.dll ) 是用于吉里吉里Z 的插件，可以让几个本体未内置的转场变得可用。

要使其可用，需要与其他插件一样，通过 [Plugins.link](../reference/Plugins.md#link) 方法进行连接。只要连接，以下转场处理器就会变得可用。

- **wave**  
  "wave" (波浪) 转场是表现基于光栅滚动的波浪并进行切换的转场。
  
  
  
  ![](../_assets/wave_trans.jpg)
  
  
  
  有以下选项。
  
  - **time (必需)**  
    以毫秒为单位指定进行转场的时间。
  - **wavetype**  
    指定波浪的运动方式。指定 0 时，转场的开头和结尾波浪细密，中间波浪舒缓。指定 1 时，开头波浪细密，逐渐变得舒缓。指定 2 时，开头波浪舒缓，逐渐变得细密。默认值为 0。
  - **maxh**  
    以像素为单位指定波浪横向宽度的最大值。值越大，波浪的起伏越深。默认值为 50。
  - **maxomega**  
    指定波浪角速度 ( rad/pixel ) 的最大值。值越大波浪越细密，越小波浪越舒缓。默认值为 0.2。
  - **bgcolor1**  
    以 0xRRGGBB 格式指定初始背景色。
  - **bgcolor2**  
    以 0xRRGGBB 格式指定最终背景色。背景色从初始背景色开始，逐渐变为最终背景色。
- **mosaic**  
  "mosaic" (马赛克) 转场是表现出矩形马赛克效果的转场。
  
  
  
  ![](../_assets/mosaic_trans.png)
  
  
  
  有以下选项。
  
  - **time (必需)**  
    以毫秒为单位指定进行转场的时间。
  - **maxsize**  
    指定马赛克矩形大小的最大值。默认值为 30。值越大马赛克越粗糙。
- **turn**  
  "turn" 转场是表现出许多小卡片翻转效果的转场。
  
  
  
  ![](../_assets/turn_trans.jpg)
  
  
  
  有以下选项。
  
  - **time (必需)**  
    以毫秒为单位指定进行转场的时间。
  - **bgcolor**  
    以 0xRRGGBB 格式指定背景色。
- **rotatezoom**  
  "rotatezoom" 转场是让转场源一边旋转一边放大或缩小的转场。
  
  
  
  ![](../_assets/rotatezoom_trans.jpg)
  
  
  
  有以下选项。
  
  - **time (必需)**  
    以毫秒为单位指定进行转场的时间。
  - **factor**  
    指定初始放大率。指定 0 时最初不可见，从中央一边旋转一边放大。指定 2 时从 2 倍放大率一边旋转一边逐渐缩小到 1 倍。也可以指定 3 以上的数或实数。默认值为 1 (1 倍)。
  - **accel**  
    指定缩放的动作是否以加速方式进行。指定 -2 以下的负数时，最初较快，逐渐变慢。指定 2 以上的正数时，最初较慢，逐渐变快。指定 0 时变为直线式的运动。不过在视觉上可能看起来并非直线。默认值为 0。
  - **twist**  
    指定朝哪个方向旋转多少。指定正数时逆时针旋转。指定负数时顺时针旋转。指定的值为旋转圈数。默认值为 2。
  - **twistaccel**  
    指定旋转的动作是否以加速方式进行。指定 -2 以下的负数时，最初较快，逐渐变慢。指定 2 以上的正数时，最初较慢，逐渐变快。指定 0 时变为直线式的运动。默认值为 -2。
- **rotatevanish**  
  "rotatevanish" 转场是让转场目标一边旋转一边缩小的转场。
  
  
  
  ![](../_assets/rotatevanish_trans.jpg)
  
  
  
  有以下选项。
  
  - **time (必需)**  
    以毫秒为单位指定进行转场的时间。
  - **accel**  
    指定缩放的动作是否以加速方式进行。指定 -2 以下的负数时，最初较快，逐渐变慢。指定 2 以上的正数时，最初较慢，逐渐变快。指定 0 时变为直线式的运动。不过在视觉上可能看起来并非直线。默认值为 2。
  - **twist**  
    指定朝哪个方向旋转多少。指定正数时逆时针旋转。指定负数时顺时针旋转。指定的值为旋转圈数。默认值为 2。
  - **twistaccel**  
    指定旋转的动作是否以加速方式进行。指定 -2 以下的负数时，最初较快，逐渐变慢。指定 2 以上的正数时，最初较慢，逐渐变快。指定 0 时变为直线式的运动。默认值为 2。
- **rotateswap**  
  "rotateswap" 转场是让转场目标与转场源一边旋转一边互换的转场。转场目标一边旋转一边移向深处，取而代之转场源一边旋转一边来到近前。
  
  
  
  ![](../_assets/rotateswap_trans.jpg)
  
  
  
  有以下选项。
  
  - **time (必需)**  
    以毫秒为单位指定进行转场的时间。
  - **twist**  
    指定朝哪个方向旋转多少。指定正数时逆时针旋转。指定负数时顺时针旋转。指定的值为旋转圈数。默认值为 1。
  - **bgcolor**  
    以 0xRRGGBB 格式指定背景色。
- **ripple**  
  "ripple" 转场是表现出波纹扩散效果并同时进行切换的转场。
  
  
  
  ![](../_assets/ripple_trans.jpg)
  
  
  
  有以下选项。
  
  - **time (必需)**  
    以毫秒为单位指定进行转场的时间。
  - **centerx**  
    指定波纹中心的 X 坐标。省略时为图像中央。
  - **centery**  
    指定波纹中心的 Y 坐标。省略时为图像中央。
  - **rwidth**  
    指定波纹的细密程度。可以指定 16, 32, 64, 128 中的任意一个，数值越小波纹越细密。省略时视为指定了 128。
  - **roundness**  
    指定波纹是变为纵向长的椭圆、正圆，还是横向长的椭圆。指定 0.0 ~ 1.0 (但不包含 0.0) 范围内的数值 (例如 0.5 等) 时，变为纵向长的椭圆。指定 1.0 时变为正圆。指定大于 1.0 的数值 (例如 2 等) 时，变为横向长的椭圆。省略时视为指定了 1.0。
  - **speed**  
    指定波浪扩散的速度。省略时视为指定了 6.0。
  - **maxdrift**  
    指定波浪的剧烈程度。省略时视为指定了 24。
  
  > **Note:**
  > ripple 转场在首次执行时，会分配相当大的内存 (约 0.5~4MB，因选项而异)，
  > 预先完成用于平滑执行转场的数值计算，并保存到该内存中。
  > 这可能需要一些时间 (约 0.01 秒~0.5 秒)。
  >
  > 如果进行转场的图像尺寸以及 centerx, centery, rwidth, roundness, maxdrift 各条件全部相同，则会复用前一次的
  > 数值计算信息。最多会保留过去 4 个条件的数值计算结果 (被缓存)。
  > 当要求对更多的新条件进行数值计算时，会从最旧的信息开始删除。
  >
  > 基于以上情况，如果经常使用此转场，可以在执行前先以假数据执行一次转场，从而避免之后的
  > 数值计算。

## 追加转场插件 ( extNagano.dll )

追加转场插件 ( extNagano.dll ) 是曾为吉里吉里2 公开的同名 DLL 的复原版，会添加 12 种转场处理器。与 extrans.dll 一样，通过 [Plugins.link](../reference/Plugins.md#link) 方法连接后即可使用。

对于任何转场，用于以毫秒为单位指定转场时间的 **time** 选项都是必需的。下面说明 time 以外的选项。

- **3duniversal**  
  根据 rule 图像各像素的颜色成分移动像素并进行切换的全能转场。rule 图像的 R(H) 被解释为移动开始时间 ( 0~255 )、G(S) 为移动速度、B(B) 为移动方向 ( 0:上 / 63:右 / 127:下 / 191:左 )。
  
  - **rule**  
    指定用于切换的 rule 图像。可以指定图像文件的路径或图层对象。
  - **type**  
    以 "RGB" 或 "HSB" 指定 rule 成分的解释方式。默认为 "RGB"。
  - **speed1, accel1, bound1**  
    指定变化前图像的基础速度、基础加速度、回弹时间 ( 0~127 )。speed1 / accel1 也有别名 s1 / a1。
  - **speed2, accel2, bound2**  
    对变化后图像的同样指定。speed2 / accel2 也有别名 s2 / a2。
- **blurfade**  
  一边模糊一边交叉淡化。
  
  - **exponent**  
    指定切换的节奏。大于 1 时前半段较缓，小于 1 时前半段较急。默认值为 1。
  - **blur1, blur1x, blur1y**  
    指定原图像的模糊量。blur1 对 x/y 两个方向指定相同的值。
  - **blur2, blur2x, blur2y**  
    指定目标图像的模糊量。blur2 对 x/y 两个方向指定相同的值。
  - **prerender**  
    指定模糊图像的生成时机。0 为每帧生成，1 为开始前生成 (平滑)，2 是 1 的轻量版。
  - **type**  
    指定模糊的种类。0 为均值模糊，1 为双线性模糊。
- **scanline**  
  按扫描线左右交替滑动进行切换。选项只有 time。
- **zoomfade**  
  一边放大原图像一边切换到下一图像。
  
  - **zoom1**  
    指定原图像的目标缩放值。
  - **zoom2**  
    指定目标图像的起始缩放值。
- **rgbfade**  
  按 RGB 成分错开时机的交叉淡化。
  
  - **delayR, delayG, delayB, delayA**  
    以 0~255 指定各成分的延迟。
- **spin**  
  将两条线旋转进行切换。
  
  - **type1, type2**  
    以 -1~11 指定旋转类型。-1 为无，0,1 为长方体旋转，4~7 为门旋转等。
- **flutter**  
  表现出将纸掀起效果的转场。
  
  - **back**  
    以 0xAARRGGBB 格式指定翻起的纸张背面的颜色。AA=00 时为前面的反色，AA=ff 时为 0xRRGGBB 的颜色。
  - **alpha**  
    指定翻起的纸张背面的透明度。
  - **slip**  
    指定纸张的偏移量。
- **book**  
  表现出翻书页效果的转场。
  
  - **dir**  
    指定翻页方向。-1 为随机，0 为将左页翻向右，1 为将右页翻向左。
- **imagewipe**  
  使用任意 rule 图像的划像。
  
  - **rule**  
    指定用于切换的 rule 图像。可以指定图像文件的路径或图层对象。
  - **dir**  
    指定划像的进行方向。0 按白→黑、1 按黑→白的顺序切换。
- **honeyturn**  
  将 extrans 的 turn 扩展为六边形的翻页表现 (在原 DLL 中也是未完成的效果)。
  
  - **size**  
    以像素为单位指定六边形一条边的长度。
  - **dir**  
    以 1~9 (与数字小键盘相同的方向) 指定各六边形的旋转方向。
  - **order**  
    以 1~9 (与数字小键盘相同的方向) 指定六边形旋转的顺序。
  - **twist**  
    指定扭转量。
- **morphing**  
  一边使三角形面片变形一边淡化。请指定三角形面片使其无间隙地铺满。
  
  - **before**  
    指定变形前的三角形群。每个三角形对应 6 个 ( ax1, ay1, ax2, ay2, ax3, ay3 ) 数值，n 个三角形就是 6n 个数值的数组。
  - **after**  
    同样以 6n 个数值的数组指定变形后的三角形群。
- **multiripple**  
  多个波纹扩散并同时切换的转场。
  
  - **count**  
    以 1~20 指定波源的数量。
  - **wavecount**  
    指定各波源的波的数量。
  - **rwidth**  
    指定各波源的波的波长。
  - **maxdrift**  
    指定各波源的波的振幅缩放。为 0 时没有波浪。
  - **roundness**  
    指定圆度。小于 1.0 为纵向长的椭圆，1.0 为正圆，大于 1.0 为横向长的椭圆。
  - **delaylast**  
    指定最后一个波源的延迟。1.0 为无延迟，越大越慢。
