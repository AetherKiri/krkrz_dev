# 图像格式转换器

## 关于图像格式转换器

图像格式转换器 (tools 文件夹中的 krkrtpc.exe) 是用于在吉里吉里的各类图像之间进行相互转换的工具。

可用于准备各种图像。



输入文件格式可以选择 BMP、PNG、JPEG、PSD，输出文件格式可以选择 BMP、PNG、TLG5、TLG6、JPEG 中的任意一种。

也可以读取或输出吉里吉里所使用的那种主图像/遮罩分离格式的透明图像。这里使用的“遮罩”一词与 alpha 通道同义。



基本上它只是转换图像格式，因此用它输出的图像应该也可以用于其他软件和工具。



另外，虽然这不是本工具独有的注意事项，但**请务必做好备份！**

## 输入图像格式

作为输入文件格式，可以使用以下格式。

- **BMP**  
  是 Windows 标准位图格式。32 bit (bpp) 格式的 BMP 被视为带 alpha 通道的 BMP。
  
  其他格式的 BMP 被视为不透明图像(不含透明信息的图像) (用于后述的主图像/遮罩分离格式时除外)。
- **PNG**  
  是 Portable Network Graphic 格式。也可以读取带透明部分(具有 alpha 通道或透明信息)的 PNG。
- **PSD**  
  是 Adobe Photoshop 3 及以后版本使用的格式。不过，本工具可读取的 PSD 存在以下重大限制。
  
  - 只能读取色彩模式为 RGB 的文件
  - 不能读取 16bit/通道 的文件
  - 仅支持无压缩和 RLE 压缩 (Photoshop 3.0 格式时仅支持 RLE 压缩)
  
  此格式不能作为主图像/遮罩分离格式读取。
  大部分数据可以读取，但也有一些数据无法读取。
  
  如果色彩模式使用了 RGB 以外的模式(CMYK 等)，请转换为 RGB。如果使用了 16bit/通道，请转换为 8bit/通道。
  
  如果包含“正常”以外混合模式的图层，在输入本工具之前先执行“合并可见部分”即可。
  
  
  
  PSD 文件的读取功能会根据输出格式中是否选择“ltAddAlpha形式で出力する”而大不相同。
  
  
  
  选择“ltAddAlpha形式で出力する”时，可以读取包含“正常”“线性减淡（添加）”“线性加深”“正片叠底”“滤色”“叠加”“强光”“柔光”“颜色减淡”“颜色加深”“变亮”“变暗”“差值”“排除”图层的 PSD 文件。另外，如果是仅由“正常”构成的图像，即使多张图层叠加也能支持 (其他模式下，多张图层叠加时无法支持)。
  
  
  
  选择“ltAddAlpha形式で出力する”时，仅支持“正常”图层和“线性减淡（添加）”图层。这种情况下，图层必须从下(深处)往上按“任意数量的‘正常’图层”“任意数量的‘线性减淡（添加）’图层”的顺序排列。“任意数量”是指 0 张，也就是完全没有图层，或者 1 张以上的图层。
  
  - **选择“ltAddAlpha形式で出力する”时可以读取的示例**  
    - “正常”图层 1 张，其上为“线性减淡（添加）”图层 1 张
    - 没有“正常”图层，只有“线性减淡（添加）”图层 1 张
    - 仅有“正常”图层 1 张
    - “正常”图层 3 张，其上为“线性减淡（添加）”图层 2 张
  - **选择“ltAddAlpha形式で出力する”时无法读取的示例**  
    - “正常”图层 1 张，其上为“线性减淡（添加）”图层 1 张，再在其上叠“正常”图层 1 张
      (线性减淡图层不能夹在正常图层之间)
    - “线性减淡（添加）”图层 1 张，其上为“正常”图层 1 张，再在其上叠“线性减淡（添加）”图层 1 张
      (正常图层不能夹在线性减淡图层之间)
    - 仅有“颜色减淡”图层 1 张
      (即使同为减淡类，能处理的也只有“线性减淡”图层)
  
  Photoshop 的“正常”相当于吉里吉里的 alpha 合成，“线性减淡（添加）”相当于吉里吉里的加法合成。ltAdditiveAlpha (加法 alpha 合成) 可以同时表现 alpha 合成和加法合成，因此可以读取这种图层结构的 Photoshop 数据。
- **JPEG**  
  可以读取全彩和灰度的一般 JPEG 格式。也可以作为后述主图像/遮罩分离格式的输入使用。
- **主图像/遮罩分离格式**  
  主图像/遮罩分离格式是指主图像(颜色信息)和遮罩(透明信息)分别为不同文件的格式。
  
  遮罩图像的文件名为在主图像文件名末尾加上 _m 的名称 (例如 test.jpg 对应 test_m.jpg)。
  
  可以作为主图像/遮罩分离格式使用的输入图像格式分别为 BMP、JPEG、PNG。主图像与遮罩的格式不同也可以。

> **Note:**
> TLG5 和 TLG6 格式不能用作输入。ERI 格式目前尚不支持。

## 输出图像格式

作为输出图像格式，可以使用以下格式。

- **24bit/32bit BMP**  
  24bit BMP 是不带 alpha 通道的 BMP。
  
  32bit BMP 是带有 alpha 通道的 BMP，是在一个文件内同时持有主图像和遮罩的 BMP。
- **PNG**  
  全彩 PNG，或带 alpha 通道的 PNG。
- **TLG5**  
  全彩 TLG5，或带 alpha 通道的 TLG5。
  
  > **Note:**
  > TLG5 格式压缩相当耗时。程序可能会看起来像停止了一样。
- **TLG6**  
  全彩 TLG6，或带 alpha 通道的 TLG6。
  
  > **Note:**
  > TLG6 格式与 TLG5 格式一样，压缩相当耗时。程序可能会看起来像停止了一样。
  
  TLG6 图像与 TLG5 图像一样，会写出标签信息。
- **主图像/遮罩分离格式**  
  这是对有透明部分的图像，把主图像/遮罩分别记录到不同文件中的方式。两者分别可以选择 BMP、JPEG、PNG。
  
  遮罩图像的文件名为在主图像文件名末尾加上 _m 的名称 (例如 test.jpg 对应 test_m.jpg)。
  
  主图像和遮罩可以采用不同的图像格式，但 BMP 与 BMP、PNG 与 PNG 的组合几乎没有意义，所以选择上述的 32bit BMP 或带 alpha 通道的 PNG 为好。
  
  只要其中一方或双方使用 JPEG，就能节省文件大小，但画质会变差。
  
  主图像/遮罩分离格式不能指定 TLG5 或 TLG6 格式。

## 标签信息

图像格式转换器会向 TLG 图像和 PNG 图像写出“标签信息”。“标签信息”是包含图像应如何显示等信息的数据。该标签信息可以通过 [Layer.loadImages](../reference/Layer.md#loadimages) 方法的返回值获取。


会写出以下标签信息。

- ****mode** (仅 TLG)**  
  图像的显示模式。如果是“不透明图像”，则写出 mode=opaque 的信息；如果输出格式为 ltAddAlpha，则写出 mode=addalpha 的信息。
  
  如果是“有透明部分的图像”且输出格式不是 ltAddAlpha，则读取 PSD 以外的文件、或仅包含“正常”图层的 PSD 文件时，mode=alpha。读取的 PSD 文件中包含“正常”以外的图层时，会写出与各混合模式对应的信息。
  
  吉里吉里在 TJS 的全局对象中有一个名为 imageTagLayerType 的字典数组，它表示 TLG 图像所带标签信息中的 mode 与图层类型如何对应，定义如下。
  
  ```
  global.imageTagLayerType = %[
      opaque      :%[type:ltOpaque            ],
      rect        :%[type:ltOpaque            ],
      alpha       :%[type:ltAlpha             ],
      transparent :%[type:ltAlpha             ],
      addalpha    :%[type:ltAddAlpha          ],
      add         :%[type:ltAdditive          ],
      sub         :%[type:ltSubtractive       ],
      mul         :%[type:ltMultiplicative    ],
      dodge       :%[type:ltDodge             ],
      darken      :%[type:ltDarken            ],
      lighten     :%[type:ltLighten           ],
      screen      :%[type:ltScreen            ],
      psnormal    :%[type:ltPsNormal          ],
      psadd       :%[type:ltPsAdditive        ],
      pssub       :%[type:ltPsSubtractive     ],
      psmul       :%[type:ltPsMultiplicative  ],
      psscreen    :%[type:ltPsScreen          ],
      psoverlay   :%[type:ltPsOverlay         ],
      pshlight    :%[type:ltPsHardLight       ],
      psslight    :%[type:ltPsSoftLight       ],
      psdodge     :%[type:ltPsColorDodge      ],
      psdodge5    :%[type:ltPsColorDodge5     ],
      psburn      :%[type:ltPsColorBurn       ],
      pslighten   :%[type:ltPsLighten         ],
      psdarken    :%[type:ltPsDarken          ],
      psdiff      :%[type:ltPsDifference      ],
      psdiff5     :%[type:ltPsDifference5     ],
      psexcl      :%[type:ltPsExclusion       ],
  ]
  ```
  
  关于各图层的类型，

  请参照。
- ****offs_x** **offs_y** **offs_unit** (TLG, PNG)**  
  仅当转换源为 PNG、且该 PNG 包含距图像左上角的偏移 (oFFs 块) 的信息时才会输出。
  
  offs_x 是水平位置距左端的距离，offs_y 是垂直位置距上端的距离。offs_unit 为 **pixel** 或 **micrometer** 之一，表示距离的单位。
- ****vpag_w** **vpag_h** **vpag_unit** (TLG, PNG)**  
  仅当转换源为 PNG、且该 PNG 包含 Virtual PAGe，即图像整体大小 (vpAg 块) 的信息时才会输出。
  
  作为能向 PNG 输出此信息的软件，有 [ImageMagick](http://www.imagemagick.org/) 实用工具；用该 **ImageMagick** 执行 trim (裁剪) 时，会输出裁剪前的图像大小作为此信息。
  
  vpag_w 是图像整体的水平大小，vpag_h 是图像整体的垂直大小，offs_unit 为 **pixel** 或 **micrometer** 之一，表示大小的单位。
- ****reso_x** **reso_y** **reso_unit** (TLG, PNG)**  
  仅当转换源为 PNG、且该 PNG 包含图像分辨率 (pHYs 块) 的信息时才会输出。
  
  reso_x 是水平方向的分辨率，reso_y 是垂直方向的分辨率。reso_unit 为 **meter**，表示分辨率的单位。

## 图像格式转换器的用法

转换的操作方法是把想要转换的文件拖放到图像格式转换器的窗口上。也可以拖放多个文件。



可以为不透明图像和有透明部分的图像分别指定不同的格式。



这里所说的“不透明图像”是指整个图像区域完全为不透明的图像(例如背景图像)。“有透明部分的图像”是指存在透明部分的图像(例如前景图像)。

另外，即使某种图像格式本身能够保存等价的信息，只要结果上图像的所有像素都完全不透明，也会被当作“不透明图像”处理。



转换结束后会显示可以确认各文件是转换成功还是出错的日志，请进行确认。



以下是对画面的说明。



![](../_assets/TPC.png)


执行后会显示上面的画面。

- **“オプションを表示”**  
  处于勾选状态时会显示下方的设置部分。取消勾选后，窗口只保留上方的部分，横向变细长。不需要设置选项时可以让窗口更紧凑。
- **“不透明な画像 - 24bit BMP”**  
  选择 24bit BMP 作为不透明图像的输出格式。
- **“不透明な画像 - PNG”**  
  选择 PNG 作为不透明图像的输出格式。
- **“不透明な画像 - TLG5”**  
  选择 TLG5 作为不透明图像的输出格式。
- **“不透明な画像 - TLG6”**  
  选择 TLG6 作为不透明图像的输出格式。
- **“不透明な画像 - JPEG”**  
  选择 JPEG 作为不透明图像的输出格式。
- **“不透明な画像 - JPEG オプション...”**  
  选择 JPEG 作为不透明图像的输出格式时，选择 JPEG 的压缩质量。
- **“透明部分のある画像 - 32bit BMP (メイン+マスク)”**  
  选择 32bit BMP 作为带透明信息的图像的输出格式。
- **“透明部分のある画像 - αチャネル付き PNG (メイン+マスク)”**  
  选择带 α 通道的 PNG 作为带透明信息的图像的输出格式。
- **“透明部分のある画像 - αチャネル付き TLG5 (メイン+マスク)”**  
  选择带 α 通道的 TLG5 作为带透明信息的图像的输出格式。
- **“透明部分のある画像 - αチャネル付き TLG6 (メイン+マスク)”**  
  选择带 α 通道的 TLG6 作为带透明信息的图像的输出格式。
- **“透明部分のある画像 - メイン/マスク分離形式”**  
  指定主图像/遮罩分离格式作为带透明信息的图像的输出格式。主图像/遮罩使用什么格式在下方选择。另外，使用 JPEG 时，点击“JPEG オプション”按钮可以选择 JPEG 的压缩质量。
- **“透明部分のある画像 - 入力画像をltAddAlpha形式であるとみなす”**  
  勾选此选项时，把输入图像视为 ltAddAlpha 形式，即适合用吉里吉里的 [Layer.type](../reference/Layer.md#type) 属性指定 ltAddAlpha 来显示的加法 alpha 合成形式。受此选项影响的输入图像格式为 BMP、PNG、主图像/遮罩分离格式，PSD 格式不受影响。
  
  不勾选此选项时，输入图像被视为 ltAlpha 形式。大多数绘图软件的输出格式和 PNG 的规格都是 ltAlpha 形式，因此通常请不要勾选此选项。
  
  在此选项未勾选、且后述的“ltAddAlpha形式で出力する”已勾选的状态下，图像格式转换器会进行从 ltAlpha 形式到 ltAddAlpha 形式的转换。
  
  勾选此选项后，“ltAddAlpha形式で出力する”选项会自动被勾选。并且“完全透明部分の色情報”选项会变为不可用 (alpha 信息和颜色信息都不再由图像格式转换器加工)。
- **“透明部分のある画像 - ltAddAlpha形式で出力する”**  
  勾选此选项时，输出图像以 ltAddAlpha 形式输出。
  
  不勾选此选项时，输出图像的格式为 ltAlpha 形式；输入来自 PSD 文件时，则为与该文件所含图层的混合模式对应的形式。
  
  各种绘图软件以及 PNG 的规格只接受 ltAlpha 形式的图像，因此在输出图像并非用于吉里吉里时，通常请不要勾选此选项。
  
  勾选此选项后，“完全透明部分の色情報”选项会变为不可用 (alpha 信息和颜色信息都不再由图像格式转换器加工)。
- **“透明部分のある画像 - 完全透明部分の色情報”**  
  指定对图像中完全透明部分的处理方式。
  
  通常，ltAlpha 形式的图像即使在完全透明的部分也持有颜色信息。该部分因为完全透明所以在显示时会被直接忽略，但在对图像进行加工 (包括用 JPEG 等压缩) 时不会被忽略。
  
  指定对这种完全透明部分的处理方式。
  
  - **除去**  
    指定“除去”后，完全透明部分的颜色信息会被去除 (准确地说，是填充为纯黑色)。
    
    通常使用此设置即可。
  - **そのまま**  
    不进行任何处理，保持原图像不变。
    
    完全透明部分如果有杂质，这些杂质也会一起被压缩，因此压缩率会变差。
  - **合成**  
    从完全透明部分周围的不透明部分的颜色来推测并合成完全透明部分的颜色。
    
    合成强度可以从 1, 2, 3, 5, 8 pixel 中选择。会从以像素为单位在此指定距离内的不透明部分像素的颜色，合成完全透明部分的颜色。值越大处理越耗时。在此指定距离之外的完全透明部分的颜色会被去除。
    
    例如用 JPEG 压缩主图像时，由于 JPEG 的特性，在颜色急剧变化的地方会产生蚊噪 (mosquito noise)。对于前景图像，如果不进行“合成”处理，在完全不透明部分与不透明部分的边界颜色急剧变化时，该处就容易产生这种噪声。进行“合成”处理时，由于会从不透明部分的颜色合成完全透明部分的颜色，因此可以减小颜色变化的差值，抑制蚊噪的产生。另外，一般的 JPEG 中颜色信息会与相邻像素混合，这一点也可以通过“合成”处理，抑制 (不进行合成时) 完全透明部分的颜色与不透明部分的颜色发生非预期混合的情况。
    
    通常请选择“除去”。完全透明的部分不需要颜色信息。而且进行去除后，图像压缩后的文件大小也可以变小。
  
  勾选“ltAddAlpha形式で出力する”时此选项会变为不可用。因为 ltAddAlpha 形式下的“完全透明”只能是不透明度 0、颜色为纯黑色。
- **“出力フォルダ - 入力ファイルと同じフォルダ”**  
  将输出的文件输出到与输入文件相同的文件夹。
- **“出力フォルダ - 指定フォルダ”**  
  将输出文件输出到下方输入框中指定的文件夹。
  
  点击“参照 ...”按钮可以显示用于选择输出文件夹的对话框。
  
  在输入框中指定相对文件夹时，可以按相对输入文件所在文件夹的位置指定。
- **“出力フォルダ - 同名のファイルがあった場合に上書きする”**  
  勾选此复选框后，如果存在同名文件则覆盖。
- **“エラーが発生しなかった場合はログを表示しない”**  
  勾选此复选框后，转换结束且转换过程中没有发生错误时，不显示用于确认日志的窗口。
- **“閉じる”**  
  结束此工具。
