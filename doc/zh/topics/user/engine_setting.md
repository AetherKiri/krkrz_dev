# 引擎设置工具
### 吉里吉里Z 中已经没有独立的引擎设置工具。  
对引擎本体指定 -userconf 启动时，会作为面向用户的引擎设置工具启动。  
用安装程序等，把在本体参数中追加了 -userconf 的快捷方式注册为引擎设置工具，就能像以往一样使用。

### 不提供开发者用的引擎设置工具。
不想在用户设置中显示的项，只要在 option\_desc\_ja.json 中设为 "user":false，或者直接删除该项本身，就不会显示。  
如果设置无法正常显示，日志中可能输出了 JSON 的语法错误，最好从控制台启动并查看日志。  
要反映这些更改，需要通过构建核心，或者使用能够更改资源的工具进行修改。  

[引擎设置的添加/编辑](../core/engine_setting.md)也请参照。
