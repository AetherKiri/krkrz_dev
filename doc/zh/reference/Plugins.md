# Plugins

Plugins 类是进行**插件**相关管理的类。无法从此类创建对象。

## 成员列表

### 方法

- [link](#link)
- [unlink](#unlink)
- [getList](#getlist)
- [canLink](#canlink)

---

### link

方法

**参数**

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `name` | `&nbsp;` | 指定要连接的插件。 |

**说明**

插件的连接

将指定的插件连接到吉里吉里引擎本体 (加载)。

---

### unlink

方法

**参数**

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `name` | `&nbsp;` | 指定要断开的插件。 |

**返回值**

断开成功则为真，失败则为假

**说明**

插件的断开

断开指定的插件。

有些插件不会响应释放 (例如对象正在使用时等)。不响应释放而失败时，会返回假。

---

### getList

方法

**返回值**

存储着已链接的插件名的数组

**说明**

获取列表

获取插件的列表。返回的数组是按链接顺序枚举插件名的结果。

---

### canLink

方法

**参数**

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `name` | `&nbsp;` | 指定要判定的插件文件名。 |

**返回值**

可以链接则为真，不可能则为假。

**说明**

判定插件是否可以链接

事先判定指定的插件文件是否可以由引擎加载 (link 可能)。不会实际执行 [Plugins.link](Plugins.md#link)。

插件不存在于自动搜索路径中，或在环境上无法 link 时，会返回假。

**相关:** [Plugins.link](Plugins.md#link)
