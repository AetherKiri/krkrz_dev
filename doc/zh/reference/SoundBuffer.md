# SoundBuffer

类是管理 MIDI 播放、PCM 播放、CD-DA 播放的类。

在 WaveSoundBuffer 类中，可以读取并处理用 [循环调谐器](../guide/LoopTuner.md) 创建的 .sli 文件。详情请参阅循环调谐器的说明。

### looping

属性 \ 访问: `r/w`

**说明**

是否进行循环播放

表示是否进行循环播放。也可以设置值。

### volume

属性 \ 访问: `r/w`

**说明**

音量

表示播放音量。也可以设置值。

用 0 ~ 100000 的数值指定，0 为完全静音，100000 为 100% 音量。

---

### volume2

属性 \ 访问: `r/w`

**说明**

第二音量

表示播放音量。可以设置值。

与 .volume 属性不同的是，该属性
不会因 .fade 方法而变化。

最终音量由 volume 属性与该属性的乘积决定。volume 属性为
100000 (100%) 且 volume2 属性也为 100000 (100%) 时，100% × 100% = 100%，
以 100% 的音量播放。volume 属性为 50000 (50%) 且 volume2 属性为 75000 (75%) 时，
50% × 75% = 37.5%，以 37.5% 的音量播放。

---

### status

属性 \ 访问: `r`

**说明**

状态

表示当前状态。

状态用字符串表示，取以下值。

`"**unload**"   : ` 媒体尚未打开

`"**play**"     : ` 媒体正在播放

`"**stop**"     : ` 媒体已停止

### open

方法

**参数**

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `storage` | `&nbsp;` | 指定想要播放的存储。<br>指定想要播放的存储。<br>指定想要播放的曲目。<br>指定数值时，将播放该曲目。指定 "驱动器号:曲目编号" 的<br>格式的字符串时，将播放该驱动器指定编号的曲目 ( 例 : "e:5" )。 |

打开媒体
