# WaveSoundBuffer.PhaseVocoder

WaveSoundBuffer.PhaseVocoder 类是通过将该实例注册到 [WaveSoundBuffer.filters](WaveSoundBuffer.md#filters) 来使用的滤波器，提供 Phase Vocoder（相位声码器）的功能。

Phase Vocoder 可以在保持播放速度的同时更改音高（变调器），也可以在保持音高的同时更改播放速度（时间伸缩器）。

### time

属性 \ 访问: `r/w`

**说明**

时间轴方向的比例

表示时间轴方向的比例。也可以设置该值。

可指定的数值为大于 0 的实数。不过，数值过小会导致 CPU 负载升高，最坏的情况下可能无法播放。另外，超过 1.95 左右后音质会变差，即使增大 overlap 也可能无法改善音质（这源于内部算法的特性）。

指定 1.0 时，时间轴方向的比例不变（播放速度不变）。

例如指定 1.5 时，时间轴方向的比例变为 1.5 倍，播放会变慢（播放需要 1.5 倍的时间）。

例如指定 0.5 时，时间轴方向的比例变为 0.5 倍，播放会变快（以倍速播放）。
time 属性和 pitch 属性都为 1 时 Phase Vocoder 滤波器也会工作，音质多少会劣化，并消耗 CPU 时间。如果两者都保持为 1 使用，最好从滤波器数组中移除该滤波器。

对该属性的更改会实时反映，但由于缓冲的关系，到实际播放为止需要 2 秒左右的时间。此外，切换时可能会混入噪声。

### pitch

属性 \ 访问: `r/w`

**说明**

频率轴方向的比例

表示频率轴方向的比例。也可以设置该值。

可指定的数值为大于 0.0 的数值。

指定 1.0 时，频率轴方向的比例不变（音高不变）。

例如指定 1.0594630943593 时，音高升高半音。

例如指定 0.9438743126817 时，音高降低半音。

time 属性和 pitch 属性都为 1 时 Phase Vocoder 滤波器也会工作，音质多少会劣化，并消耗 CPU 时间。如果两者都保持为 1 使用，最好从滤波器数组中移除该滤波器。

对该属性的更改会实时反映，但由于缓冲的关系，到实际播放为止需要 2 秒左右的时间。

### window

属性 \ 访问: `r/w`

**说明**

窗口大小

表示 PhaseVocoder 内部使用的 FFT（快速傅里叶变换）的窗口大小（帧大小）。
请指定 64~32768 之间的 2 的幂数值。默认为 4096。

增大该数值时，频率轴方向的分辨率会变高（音高不易走调），但时间轴方向的分辨率会变低（声音的起音会变迟钝）。

数值越大，CPU 占用越多。请找出不降低音质所需的最低值。

对于 44.1KHz 的音频，窗口大小=256 左右比较合适。对于乐曲，窗口大小=4096 左右比较合适。

对该属性的更改会在执行 [WaveSoundBuffer.open](WaveSoundBuffer.md#open) 方法时反映。

### overlap

属性 \ 访问: `r/w`

**说明**

重叠计数

表示重叠计数（过采样系数）。

请指定 0 或 2~32 之间的 2 的幂数值。默认为 0。

指定 0 时，会根据当前 time 属性的值设置合适的值。

增大该数值时，时间轴方向的分辨率会变高。特别是在减慢播放速度时，指定较大的数值比较好。

数值越大，CPU 占用越多。

对该属性的更改会实时反映，但由于缓冲的关系，到实际播放为止需要 2 秒左右的时间。此外，切换时可能会混入噪声。
