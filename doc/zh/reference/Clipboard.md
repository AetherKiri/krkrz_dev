# Clipboard

Clipboard 类是提供访问 OS **剪贴板**功能的类。无法从该类创建对象。

在 Windows 原生 ( WINVER ) 构建与 SDL3 构建双方均可使用
( SDL3 构建自 2026-08-16 起支持。在此之前是什么都不做的空实现 )。
在针对没有剪贴板的平台的构建中，写入会被忽略，
读取始终为 void，[hasFormat](#hasformat) 始终为假。

位图 ( [setAsBitmap](#setasbitmap) / [getAsBitmap](#getasbitmap) ) 目前仅支持
Windows 原生 ( WINVER ) 构建，
在其他构建中总是返回假并且什么都不做。

### asText

属性 \ 访问: `r/w`

**说明**

文本格式

表示剪贴板中当前存在的文本格式数据。也可以写入值。

读取值即可获取剪贴板中当前的文本格式数据。剪贴板中没有文本格式数据时，会得到 void。

写入值即可将文本格式数据存入剪贴板。

---

### hasFormat

方法

**参数**

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `format` | `&nbsp;` | 指定要确认是否存在的格式。<br>`cbfText` ( 文本格式 ) 和 `cbfBitmap` ( 位图格式 ) 可以指定。 |

**返回值**

指定的格式存在于剪贴板中则为真，不存在则为假

**说明**

指定的格式是否存在于剪贴板中

可以查询指定的**格式**是否存在于剪贴板中。

OS 提供的剪贴板可以同时持有多种格式，因此可以用该方法查询其中是否存在特定格式。

---

### setAsBitmap

方法

**参数**

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `layer` | `&nbsp;` | 指定持有要写入的图像的 [Layer](Layer.md) 对象。 |

**返回值**

能写入剪贴板时为真，否则为假

**说明**

将图层的图像写入剪贴板

将指定图层的主图像以位图格式存入剪贴板。

由于要传递给其他应用程序，α 值会被压平为 255 ( 不透明 )。

---

### getAsBitmap

方法

**参数**

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `layer` | `&nbsp;` | 指定作为图像读取目标的 [Layer](Layer.md) 对象。 |

**返回值**

能从剪贴板读取时为真，没有位图格式的数据等情况下为假

**说明**

将剪贴板的图像读取到图层

将剪贴板中的位图格式数据读取到指定的图层。

图层的**图像尺寸**会配合剪贴板中的图像而更改
( 图层的显示尺寸不会改变，因此如有必要请调用 [Layer.setSizeToImageSize](Layer.md#setsizetoimagesize) )。
