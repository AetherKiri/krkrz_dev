# Matrix44

这是 4x4 矩阵。
请注意，由于面向 OpenGL，它是列优先矩阵(列优先在运算量上更有利)。
从 DirectX 等角度来看，会感觉它像被转置过(在着色器 HLSL 中同样是列优先，是一致的)。
