### ConeGeometry

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `radius` | `1` | 底面半径 |
| `height` | `1` | 高度 |
| `radialSegments` | `16` | 圆周方向的分段数 |
| `heightSegments` | `1` | 高度方向的分段数 |
| `openEnded` | `false` | 是否打开底面 |
| `thetaStart` | `0` | 圆周方向的起始角度 |
| `thetaLength` | `TWO_PI` | 圆周方向的角度范围 |
