# 词元

## 词元

脚本在解释过程中，全部会被分解为称为词元（token）的单位来处理。

词元与下一个词元的分界因词元的种类而异。

## 裸单词

“裸单词”是指在脚本中直接书写的、未经 `""` 或 `''` 引号(引用)的特定字符序列。

“裸单词”具有以下规则。

- 由字母的小写、大写、'`_`'(下划线)、数字、所谓全角字符构成。不过数字不能出现在开头。
- 这些字符连续出现到结束为止，被作为一个“裸单词”处理

```
	ampan  // OK
	123a // 数字が先頭に来ているので NG
	_asdf // アンダーバーは先頭にくることができるので OK
	continue // これは予約語 OK
	全角文字 // いわゆる全角文字は「裸の単語」として OK
```

“裸单词”进一步分为保留字和标识符。

## 保留字

保留字如下，不是标识符。“裸单词”中不是保留字的全部是标识符。



`
break  continue  const  catch  class  case

debugger  default  delete  do  extends  export

enum  else  function  finally  false  for

global  getter  goto  incontextof  Infinity

invalidate  instanceof  isvalid  import  int  in

if  NaN  null  new  octet  protected  property

private  public  return  real  synchronized  switch

static  setter  string  super  typeof  throw

this  true  try  void  var  while  with`




这些保留字作为构成脚本语法的重要用途，各自具有特殊的含义。其中一些会被用作运算符。

不过，在当前版本中并非所有这些保留字都在使用。

## 标识符

“标识符”是“裸单词”中不是保留字的全部。它们用于编写者可以自由命名的变量、函数、类名等。

标识符即使包含保留字，只要其本身不是保留字，就不会被当作保留字，而是被识别为标识符。

## 符号

符号类也会被分解为词元。符号类包括以下这些。



`>>>=  >>>  >>=  >>  >=  >  <<=  <=

<->  <<  <  ===  ==  =>  =  !==  !=  !

&&=  &&  &=  &  ||=

||  |=  |  ...   .   ++  +=  +  -=  --  -  *=

*  /=  /  \=  \  %=  %  ^=  ^  [  ]  (  )  ~

?  :  ,  ;  {  }  #  $`



这些会按最长匹配切分为词元。例如，`++` 不会被分解为 `+` 和 `+`，而是被分解为一个符号 `++`。如果想将它们记述为各自独立的 `+` 和 `+`，需要在 `+` 与 `+` 之间插入空格等。



符号类各自具有作为构成语法的要素的重要含义。符号中的一些会被用作运算符。

## 数值字面量

数值字面量是以数字或 `.` (小数点)开头的。`TJS2` 认识以下形式。

普通地书写数值，就会直接成为十进制数值字面量。

```
	0
	3.1
	342.3
	1
```

另外，十进制可以使用 `e` 或 `E` 进行以 10 为底的**指数表示**。`e` 和 `E` 含义相同。

```
	1e-3   // 1×10-3
	3.4e10   // 3.4×1010
	9.3E-2  // 9.3×10-2
```

以 `0x` 或 `0X` 开头时，即为**十六进制**表示。`0x` 和 `0X` 含义相同。

```
	0x1234
	0Xff
	0x3f33
```

以 `0b` 或 `0B` 开头时，即为**二进制**表示。

```
	0b0100
	0B0010100010100001
```

以 `0` 开头时，会被当作**八进制**处理。

```
	01234
	033
```

十六进制、八进制、二进制也可以使用小数形式或基于 p 的指数表示。p 是以 2 为底的指数表示。

```
	0b1.1    // 1 + 1/2 で 1.5 を表す
	0x2.f    // 2 + 15/16 で 2.9375 を表す
	0x1p8    // 1 × 28 で 256.0 を表す
```

数值字面量只要其字符是数值字面量的构成字符，就会被作为一个数值字面量处理。

## 字符串字面量

字符串字面量(string literal)是用 `""` (双引号) 或 `''`(单引号)包围的内容。使用双引号或单引号都可以。

不过，在 `""` (双引号) 中 '(单引号)、在 `''`(单引号)中 `"` (双引号)，都不再需要用 `\` 转义。

```
	"this is a string."
	'this is also a string.'
	"Can't use without a quotation."
```

在字符串中，`**\**` (反斜杠) 具有特殊含义。其含义随 \ 之后跟随的字符而变化。在 \ 之后接特殊指定的写法称为**转义**。

```
\\    : \ マーク自体
\'    : ' (シングルクオーテーション)
\"    : " (ダブルクオーテーション)
\a    : BEL (可聴ベル)
\b    : BS (後退)
\f    : FF (フォームフィード)
\n    : LF (改行)
\r    : CR (復帰)

\t    : HT (水平タブ)
\v    : VT (垂直タブ)
\xH   : H=16 進数 ( H が文字コードを表します )
\XH   : 上に同じ
```

在 `\xH` 形式中，H 部分指定十六进制数。这样，该十六进制数就会被当作字符编码，替换为单个字符。

```
	'Can\'t help'  ( \' を用いている )
	"\x1234"     ( ワイド文字としての 0x1234 という文字コードの文字 )
```

另外，在 `\xH` 形式中，只要 \x 之后继续跟随构成十六进制数的字符 ( 0~9、A~F、a~f )，这些字符就会被视为 H 部分。不过，宽字符大小为 16bit 的环境最多识别 4 位，32bit 机器最多识别 8 位 ( 在 Windows 上为 16bit，在 Linux 和 Solaris 上为 32bit )。

如果写成 `"\x22An Apple"`，开头会被当作 `\x22A`。要避免这种情况，请写成 `"\x22" "An Apple"`，将字符串分开后连续书写。在 TJS 中，像这样字符串字面量连续出现时，会被视为一个字符串。



关于字符串，请也参照 [字符串](string.md)。

## 带 @ 的字符串字面量

在字符串字面量前面放置 @ 后，该字符串字面量中从 & 到 ; 之间的部分，或从 ${ 到 } 之间的部分会被视为表达式，求值结果会被展开到该处 (在 & 与 ; 之间或 ${ 与 } 中写表达式，其结果就会被嵌入该处)。

不想展开 & 或 $ 时，可以通过在 & 或 $ 之前放置 \ 来避免展开 & 或 $。

```
	@"1+2=&1+2;"  ( "1+2=3" という文字列になる )
	@"変数 f の内容は &f; です"  ( 変数 f の内容を &f; の場所に展開する )
	@"関数 func を呼び出した結果は &func(); です"  ( 式として有効なものならば & と ; の間に記述可 )
	@"関数 func を呼び出した結果は ${func()} です"  ( 上と同じ )
	@"true \&\& false は &true && false;"  ( & の前に \ を書けば & は展開されない )
```

在此处书写的表达式可以访问从该字符串所在位置可及的范围内的变量等 (包括局部变量)。

## 字节序列字面量

字节序列字面量是用 `<%` 和 `%>` 包围的内容，其中可以书写字节序列数据 ( 二进制数据 )。

数据是用空格等分隔的两位十六进制数，可以指定多个。

```
	<% 00 01 02 03 %>
	<% ff ff ff 00 04 0f ff 30 %>
```

关于字节序列，请也参照 [字节序列](octet.md)。

## 正则表达式模式

正则表达式模式是用 `/` 和 `/` 包围的内容，其中可以书写正则表达式模式。

在正则表达式模式后面可以接着书写标志字符：g 是全局搜索标志 ( 匹配所有找到的内容；没有这个标志时只匹配第一个 )，i 是英文字母不区分大小写的标志，l 是进行本地化排序（collation）的标志。

这样书写的正则表达式模式会被当作 RegExp 类的对象处理。

```
	/[0-9]-[0-9]-[0-9]/
	/^;\s*(.*?)\s*=(.*)$/
	/start(.*?)end/gi
```

关于正则表达式模式，请也参照 [RegExp 类](regexp.md)。
