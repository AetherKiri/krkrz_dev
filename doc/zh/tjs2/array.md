# Array 类

## Array 类

Array 类是用于处理**数组**的类。

创建这个类的对象后，通过间接成员选择运算符指定的下标，就可以像数组一样使用。下标是整数。0 表示开头的元素，1 表示其后的元素。指定负整数时，会被视为从数组末尾开始指定 (-1 表示最后的元素)。

```
	var a = new Array();
	var i;
	for(i=0;i<100;i++) a[i]=i;
```

数组的大小不需要声明。会自动扩展到所指定下标的大小，未代入任何值的元素会被初始化为 void。

另外，有 count 属性，它表示数组的大小。向 count 属性赋值也可以改变数组的大小。

## 表达式中的数组

使用 `**[ ]**`，即可在表达式中当场写出 `Array` 类的对象。在 `[ ]` 中以逗号分隔，列出作为初始元素的表达式。例如，

`
var ar = ["a", "b", "c"];
`

这样记述的话，`ar` 中会被代入对包含 `"a" "b" "c"` 元素的 `Array` 类对象的引用。

## count

count 属性表示数组的大小。

## load

load 方法从文件读取数组。

```
構文 : load(<ファイル名>, <モード=''>)
```

从文本文件读取数组。文件的文本逐行进入各元素，最终 count 属性会与文件的行数相同。

在模式中指定读取文件时的模式字符串。这因 TJS 运行的环境而异。在 "o" 之后用十进制指定偏移量，则会从文件的该字节位置开始读取。

取决于 TJS 运行的环境，此方法与 save 方法、saveStruct 方法可能无法使用。

load 方法返回这个 Array 类的对象自身。

## save

save 方法把数组写出到文件。

```
構文 : save(<ファイル名>, <モード=''>)
```

把数组写出到文件。各个成员逐行输出，但对对象、类、函数等的引用会成为空行。

在模式中指定写入文件时的模式字符串。这因 TJS 运行的环境而异，在吉里吉里的情况下，指定 "c" 会对文件进行简单的加密 (可以直接用 load 方法读取)。指定 "z" 可以压缩保存文件 (不能与 "c" 并用；这也可以直接用 load 方法读取)。在 "o" 之后用十进制指定偏移量，则会从文件的该字节位置开始写入。

save 方法返回这个 Array 类的对象自身。

## split

split 方法分割字符串。

```
構文 : split(<パターン/デリミタ集合>, <文字列>, <(予約)>, <空の要素を無視するか=false>)
```

初始化数组，并把用模式或分隔符集合切分的字符串复制到这个数组中。

第 1 个参数指定模式或分隔符集合。

模式必须是正则表达式对象。

分隔符集合中指定作为分隔记号的字符。通过指定字符串，可以指定多个分隔字符。

第 3 个参数是为将来版本预留的。

“是否忽略空元素”指定在对空元素 (例如以逗号作为分隔符时的 ,,,,, 等) 不将其复制到数组的情况下为 true。

请注意参数的顺序。

## join

join 方法把数组连接成一个字符串。

```
構文 : join(<デリミタ>, <(予約)>, <空の要素を無視するか=false>)
```

用分隔符连接数组的各元素，返回连接后的字符串。

“是否忽略空元素”为 true 时，元素中的 void 会被忽略。

```
	var ar = [ "a", "b", void, "d" ];
	var s1 = ar.join(","); // s1 には "a,b,,d" が代入される
	var s2 = ar.join(",",,true); // s2 には "a,b,d" が代入される
```

## reverse

reverse 方法把数组元素的排列反转。

```
構文 : reverse()
```

## sort

sort 方法对数组进行排序 (重新排列)。

```
構文 : sort(<ソート順='+'>, <安定ソートを行うか=false>)
```

排序顺序是以下字符串之一。升序是从小到大重新排列，降序则相反。省略时视为指定了 '+'。

```
"+"  : 昇順 (通常の < 演算子での比較)
"-"  : 降順
"0"  : 数値による昇順 ( 10,2,1 は 1,2,10 に並び替えられます )
"9"  : 数値による降順
"a"  : 文字列による昇順 ( "a","c","b" は "a","b","c" に並び替えられます )
"z"  : 文字列による降順
```

可以代替排序顺序字符指定函数。函数带 2 个参数。请指定当第 1 个参数应当排在第 2 个参数之前时返回真的函数 (请注意，这与传给 JavaScript 的 sort 方法的函数在返回值的含义上不同)。

第 2 个参数指定是否进行稳定排序。省略时视为指定了 false，进行不稳定的排序。稳定排序中，相同位次的数组元素在排序后仍保持相同的顺序。不稳定排序的情况下，不保证相同位次的数组元素在排序后仍为相同的顺序。

```
	var array = [ 0, 1, 2, 10, 12, 14, 4, 6, 2 ];
	array.sort();
		// ↑ メソッド実行後、array は [0, 1, 2, 2, 4, 6, 10, 12, 14] に
	array.sort('-');
		// ↑ メソッド実行後、array は [14, 12, 10, 6, 4, 2, 2, 1, 0] に
	array.sort('a');
		// ↑ メソッド実行後、array は [0, 1, 10, 12, 14, 2, 2, 4, 6] に

	var array = [ "hoge", "foo" , "bar", "baz" ];
	array.sort();
		// ↑ メソッド実行後、array は ["bar", "baz", "foo", "hoge"] に

	var array = [ "abcd", "abc", "ab", "a" , "b", "c" ];
	array.sort(function(a,b) { return a< b; } );
		// ↑ '+' の指定と同じ意味

	var array = [ "abcd", "abc", "ab", "a" , "b", "c" ];
	array.sort(function(a,b) { return a.length < b.length; } );
		// ↑ 文字列の長さの短い順
		// (長さが同じ"a" "b" "c" がソート後も "a" "b" "c"
		// の順番である保証はない)

	var array = [ "abcd", "abc", "ab", "a" , "b", "c" ];
	array.sort(function(a,b) { return a.length < b.length; }, true );
		// ↑ 文字列の長さの短い順
		// (長さが同じ"a" "b" "c" はソート後もこの順番である)
```

## saveStruct

saveStruct 向文件输出结构化数据。

```
構文 : save(<ファイル名>, <モード=''>)
```

saveStruct 方法把元素的状态以可复原的形式输出到文件。

各元素可以包含字符串、实数、字节序列、整数。另外，元素中有对象时，仅限于该对象是 Array 类或 Dictionary 类的对象的情况下，该对象的内容也会输出到文件。除此以外的元素会输出 void。

例如，

```
	([ 1, 2, 3, [4, 5], %[ a : 1, b : 2 ], "文字列" ]).saveStruct("out.txt");
```

则

```
(const) [
	1,
	2,
	3,
	(const) [
		4,
		5
	],
	(const) %[
		"a" => 1,
		"b" => 2
	],
	"文字列"
]
```

会输出这样的内容。把整个文件作为一个表达式来求值，即可复原与保存时相同的结构。

这里的 (const) 表示 [ ] 或 %[ ] 的内容只有常数项。编译器发现这个 (const) 时，会假定紧随其后的表达式中的字典数组或数组仅包含常数项，从而可以高效读取。

saveStruct 方法返回这个 Array 类的对象自身。

## assign

assign 方法复制数组。

```
構文 : assign(<コピー元配列>)
```

原样复制由参数指定的其他数组的内容。

把字典数组 (Dictionary 类的对象) 指定为复制来源数组时，会成为该字典数组的各成员按名字、值的顺序交替出现的数组。成员的顺序不定。

## assignStruct

assignStruct 方法连同结构一起复制数组。

```
構文 : assignStruct(<コピー元配列>)
```

原样复制由参数指定的其他数组的内容。

与 assign 方法不同，成员中有数组或字典数组时，也会递归复制其内容 (assign 方法的情况下只复制引用)。

## clear

clear 方法删除数组的所有元素。

## erase

erase 方法删除指定下标的元素。

```
構文 : erase(<添え字>)
```

删除指定位置上的元素。该下标之后的元素会逐个向前移动并填满。下标超出范围时会发生异常。

## remove

remove 方法删除具有与指定值相同值的元素。

```
構文 : remove(<値>, <すべて削除するか=true>)
```

将指定值与各元素进行识别比较 (**===** 运算符的行为)，删除一致的元素。

“是否全部删除”为 false 时，只删除最先找到的元素。否则删除找到的所有元素。

## insert

insert 方法把指定的值插入到指定的位置。

```
構文 : insert(<位置>, <値>)
```

在位置所示的下标位置插入值所示的元素。该位置之后的元素会逐个向后移动。

## add

add 方法把指定的值追加到数组末尾。

```
構文 : add(<値>)
```

在数组末尾追加值所示的元素。

该方法返回值被添加的位置。

## find

find 方法返回指定值最先出现的下标。

```
構文 : find(<値>, <検索開始位置=0>)
```

从搜索开始位置的下标起依次查找指定值，返回最先出现的下标。未找到指定值时返回 -1。

比较使用识别比较 (=== 运算符的行为)。

## push

push 方法把指定的元素追加到数组末尾。

与 add 方法不同，该方法返回添加后的数组大小。另外，指定多个参数时，会按顺序添加所有参数。

```
構文 : push(<値>, ...)
```

## pop

push 方法从数组末尾取出一个元素并返回它。取出的元素会从数组中删除 (数组大小减一)。

该方法返回取出的元素。没有元素时返回 void。

```
構文 : pop()
```

## unshift

unshift 方法把元素添加到数组开头。指定多个元素时，可以把多个元素添加到开头。这种情况下，例如按 a, b, c 的顺序传入时，数组开头的元素会按 a, b, c 的顺序排列。

该方法返回添加后的数组大小。

```
構文 : unshift(<値>, ...)
```

## shift

shift 方法从数组开头取出一个元素并返回它。取出的元素会从数组中删除 (数组大小减一)。

该方法返回取出的元素。没有元素时返回 void。

```
構文 : shift()
```
