# for 语句

## for 语句

`for` 语句与 `while` 语句相似，但要更复杂一些。

语法如下。

`
for(第 1 节;第 2 节;第 3 节)
语句或块
`


这里，第 1 节指定希望在进入循环之前执行的表达式。也可以在这里进行变量声明，在此声明的变量在循环期间一直有效 (退出循环时会被删除)。也可以省略。



第 2 节指定条件表达式。只要该条件表达式为 `true`，语句或块就会被反复执行。省略时，被视为恒为真。



第 3 节指定希望在语句或块的最后执行的表达式。也可以省略。



其运行方式如下。

(1) 首先执行第 1 节

(2) 对第 2 节求值，若为假，则语句或块不被执行就结束

(3) 执行语句或块

(4) 执行第 3 节

(5) 对第 2 节求值，若为假则跳出循环

(6) 从 (3) 开始重复



如果块中有 `**break**` 语句，则在该时刻跳出循环。如果有 `**continue**` 语句，则跳转到 (4)。

```
	var i,a=1;
	for(i=1;i<5;i++)
	{
		a*=i;
	}

	var i;
	for(i=0;i<10;i++)
	{
		if(obj[i]==0) continue; // continue しても i++ が実行される
		if(obj[i]==1) break; // break するとその場で抜ける
		func(obj[i]);
	}
```
