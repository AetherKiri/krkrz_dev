# 异常处理

## 异常处理

**异常**是指在通常处理中无法设想的所谓“异常”，多数情况下请将其视为与“错误”相同。

## 异常发生的位置

程序中的任何位置都可能发生异常。

引发异常也称为“抛出异常 (throw)”。

例如，假设以下脚本引发了错误。

```
	"3%0"!; // "0 で除算をしようとしました" 例外が発生する
```

像这样，有些情况下明显会发生异常，也有些情况下无法确定是否会发生。

## 异常的捕获

使用 `**try**` (尝试) 关键字和 `**catch**` (捕获) 关键字，即可捕获异常。

例如，为了捕获上面的例子中可能发生的异常，可以编写如下脚本。

```
	try // 例外が発生するするかもしれないので
	{
		func1(); // ここでは例外が発生するかもしれない
	}
	catch // 例外を捕捉する
	{
		// 例外がおきたとき、ここが実行される
		inform("画像を読み込むことができません。"); // メッセージを表示する
	}
```

这样，只要在 try 块内编写可能发生异常的处理，当异常发生时就会执行 catch 块。错误处理可以像这样简洁地编写。



如果 try 块中什么异常都没有发生，catch 块也不会执行。



在 try 块中可以编写任何内容。像本例这样，有时能明确知道该行可能发生异常；而即使是在函数调用、乃至更深层函数调用处发生异常，只要预先写好 try ... catch，就能在异常发生之时回到这里。



发生异常时，块中剩余的处理会被中断，并回到 try 所在的位置。



如果在 catch 块中又发生异常，异常不会在此处被捕获。异常会就这样沿着函数调用等向上回溯，如果其他地方有 try 正在进行异常捕获，就会在那里被捕获。



从异常被抛出到抵达 catch 块之间，也可能发生别的异常，但此时的运行结果未定义。



如果异常在脚本内的任何地方都没有被捕获，异常就会直接离开脚本并交给应用程序，在那里被处理。

> **Note:**
> 通常，这类异常会作为错误中断执行，因此建议尽量在可能发生错误的地方编写 try ... catch。

## 异常对象

与异常有关的各种信息会随同名为 **Exception** 的类的对象一起被抛出。这个对象称为异常对象。可以用 catch 接收它。详情请参阅 [Exception 类](exception.md)。

例如，可以编写如下脚本。

```
	try
	{
		loadImages("nothing.jpeg"); // 例外が発生するかもしれない処理
	}
	catch (e) // e という変数で例外を受け取る
	{
		// e.message は、例外とともに投げられたメッセージ文字列を表します。
		// これには例外が発生した理由が説明されている場合があります。
		inform("画像を読み込むことができません。\n"+e.message);
	}
```

这样，在 catch 后的圆括号内写上用于接收的变量，就可以用该变量接收异常对象。

该变量的作用域从 catch 之后的块内开始，并随该块一起结束。该变量无需事先声明。

## throw 语句

也可以抛出异常。要抛出异常，使用 `**throw**` 关键字。

例如，可以编写如下脚本。

```
	function pow2(n)
	{
		// 2 の n 乗を計算する n は正の整数でなければならない
		if(n<0) throw new Exception("負の数は指定できません。");
			// ↑ 例外を発生する
		return 1<<n;
	}
```

向该函数的参数传入 -1 等负数时，会发生异常。抛出异常的是以下语句。

```
throw new Exception("負の数は指定できません。");
```

关于 `new Exception("負の数は指定できません。")`，这是以字符串为参数创建 Exception 类的对象。详情请参阅 [Exception 类](exception.md)。然后，用 throw 关键字抛出这个新创建的对象。

用 throw 关键字可以抛出的并不限于 Exception 类的对象。数值、字符串，甚至连对函数的引用也可以抛出。不过，推荐抛出 Exception 类或由它派生的类的对象。因为这样一来，捕获时在 catch 块中，只需假定到来的必然是 Exception 类的对象来编写即可。

## 再次抛出异常

用 catch 捕获了异常固然可以，但某处也许还声明着可能接收该异常的 try，这种情况下可以再次抛出异常。

可以编写如下脚本。

```
	function tryloadimage()
	{
		try
		{
			primaryLayer.loadImages("test1.bmp"); // test1.bmp を読んでみる
		}
		catch(e)
		{
			inform("画像読み込みに失敗しました。");
			throw e; // メッセージを表示はするが、例外を再び投げる
		}
	}

	function test()
	{
		// tryloadimage を呼び出し、画像読み込みが成功すれば true
		// そうでなければ false を返す関数
		try
		{
			tryloadimage();
		}
		catch
		{
			return false;
		}
		return true;
	}
```

这里调用 test()，如果图像加载失败，会由 inform 方法显示消息，但由于异常会被再次抛出，因此能够被 test 函数内的 catch 捕获。
