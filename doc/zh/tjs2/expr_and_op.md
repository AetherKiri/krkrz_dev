# 表达式与运算符

## 表达式与运算符

**表达式**是运算符与操作数的集合，或者是字面量。



通常，可以像下面这样写在脚本中。



`
表达式;

`


像这样在表达式后面加上分号，该表达式就会当场被求值( = 执行 )，而该表达式的结果会被丢弃。

```
	a = b;
	// 演算子 = の動作によって、a 変数に 変数b が代入される

	func();
	// 演算子 ( ) の動作によって、func が関数として呼び出されるが、関数の戻り値
	// は捨てられる

	1 + 3;
	// + 演算子の動作によって、1 と 3 が加算されるが、結果は捨てられる(実際はこ
	// の式は意味を持たないので実行すらされない)
```

## 真与假

有些运算符会处理真或假 (逻辑值)。运算结果为 0 时为假，0 以外时为真。

对字符串询问真伪时，空字符串为假；否则会尝试转换为数值，成功时以该数值的结果作为真伪，失败则为假。

## 运算符

下面按优先级从低到高的顺序依次说明运算符。

## if 运算符

if 运算符 `if` 是仅当对右侧内容求值的结果为真时，才对左侧内容求值的运算符。

```
	a=b if b!=0; // b が 0 でなければ a に b を代入
```

无法获得运算符的结果。

## 顺序运算符

顺序运算符 `**,**` (逗号) 先对左侧内容求值，接着对右侧内容求值，除此之外不做任何事。作为整个运算符，结果是右侧内容求值的结果。连续写多个逗号时，会从左侧内容开始依次求值。

```
	c = (a=1, b=2); // a=1, b=2 が評価され、c には 2 が代入される
	a=1, b=2, c=3; // a=1, b=2, c=3 の順に評価される
```

## 赋值运算符

赋值运算符有以下这些。



`**=**  **<->**  **&=**  **|=**  **^=**  **-=**  **+=**  **%=**  **/=**  **\=**  ***=**  **||=**  **&&=**  **>>=**  **<<=**  **>>>=**`


其中，= 运算符是简单赋值运算符，其行为是将右侧内容的求值结果赋给左侧内容，作为整个运算符的值则为右侧内容的求值结果。

```
	a = 0;  // a に 0 を代入
	a = b = c = 0; // c , b, a の順に 0 を代入
```

`<->` 运算符进行交换。首先对左侧内容求值，接着对右侧内容求值。然后，将右侧的求值结果赋给左侧，将左侧的求值结果赋给右侧。无法获得运算符的结果。

目前，左右两边的表达式分别为了获取表达式的值和向表达式赋值而**会被求值 2 次**。将来此规格可能会更改，因此请不要编写依赖求值次数的代码。



除此之外的运算符全部采用 `运算符=` 的形式，写成 `A 运算符= B` 时，其含义为 `A = A 运算符 B`。作为整个运算符的值，就是运算结果的值。

## 条件运算符

条件运算符 `**? :**` 是三目运算符。写成 `A ? B : C` 的形式时，会对 A 求值，若为真则对 B 求值并忽略 C；若为假则对 C 求值并忽略 B。作为整个运算符的值，是被求值的那一方 (B 或 C) 的值。



条件运算符可以用作左值。

```
	a = b==0 ? c : b; // b が 0 だったら a に c を、 b が 0 でなかったら a に b を代入
	b==0 ? (a=c) : (a=b); // 上と同じ意味
	(a ? b : c ) = d; // a が真ならば b に、a が偽ならば c に、 d を代入 (左辺値として使用した例)
```

## 逻辑 OR 运算符

逻辑 OR 运算符 `**||**` 首先对左侧内容求值，若为真则忽略右侧内容，整个运算符的结果为真。若左侧内容的求值结果为假，则对右侧内容求值，其真伪结果即为整个运算符的结果。

## 逻辑 AND 运算符

逻辑 AND 运算符 `**&&**` 首先对左侧内容求值，若为假则忽略右侧内容，整个运算符的结果为假。若左侧内容的求值结果为真，则对右侧内容求值，其结果即为整个运算符的结果。

## 按位 OR 运算符

按位 OR 运算符 `**|**` 进行逐位的逻辑 OR。按左侧内容、右侧内容的顺序求值，将结果作为整数进行逐位 OR 所得的结果即为整个运算符的值。

## 按位 XOR 运算符

按位 XOR 运算符 `**^**` 进行逐位的逻辑 XOR。按左侧内容、右侧内容的顺序求值，将结果作为整数进行逐位 XOR 所得的结果即为整个运算符的值。

## 按位 AND 运算符

按位 AND 运算符 `**&**` 进行逐位的逻辑 AND。按左侧内容、右侧内容的顺序求值，将结果作为整数进行逐位 AND 所得的结果即为整个运算符的值。

## 等同运算符

`**==**  **!=**  **===**  **!==**` 属于等同运算符类。

- **`==` 运算符**  
  `==` 运算符先对左侧内容求值，再对右侧内容求值。两者一致时整个运算符为真，不一致时为假。若两侧的运算结果类型不同，则会先经过适当的转换再比较。例如，`-1 == '-1'` 为真。
- **`!=` 运算符**  
  `!=` 运算符是 `==` 运算符真伪反转后的结果。
- **`===` 运算符**  
  `===` 运算符被称为识别比较运算符，与 `==` 运算符相同，但不进行类型转换，类型也必须一致才为真。
- **`!==` 运算符**  
  `!==` 运算符是 `===` 运算符真伪反转后的结果。

## 比较运算符

`**<**  **>**  **<=**  **>=**` 属于比较运算符类。

- **`<` 运算符**  
  `<` 运算符先对左侧内容求值，再对右侧内容求值。左侧的求值结果小于右侧的求值结果时为真，否则为假。
- **`>` 运算符**  
  `>` 运算符先对左侧内容求值，再对右侧内容求值。右侧的求值结果小于左侧的求值结果时为真，否则为假。
- **`<=` 运算符**  
  `<=` 运算符先对左侧内容求值，再对右侧内容求值。左侧的求值结果小于或等于右侧的求值结果时为真，否则为假。
- **`>=` 运算符**  
  `>=` 运算符先对左侧内容求值，再对右侧内容求值。右侧的求值结果小于或等于左侧的求值结果时为真，否则为假。

要比较的双方都是字符串时，会按宽字符编码顺序(通常为 UNICODE)进行比较。

## 移位运算符

`**>>**  **<<**  **>>>**` 属于移位运算符类。

- **`>>` 运算符**  
  `>>` 运算符首先对左侧内容求值，接着对右侧内容求值。将左侧的结果作为整数，带符号向右移位右侧结果所指定的次数，所得的结果即为整个运算符的结果。
- **`<<` 运算符**  
  `<<` 运算符首先对左侧内容求值，接着对右侧内容求值。将左侧的结果作为整数，向左移位右侧结果所指定的次数，所得的结果即为整个运算符的结果。
- **`>>>` 运算符**  
  `>>>` 运算符与 `>>` 运算符相同，但会将左侧的求值结果作为无符号整数处理。

## 加减运算符

`**+**  **-**` 分别是加法运算符和减法运算符。

- **`+` 运算符**  
  `+` 运算符先对左侧求值，再对右侧求值。若两个结果都是数值，则进行数值加法，作为整个运算符的结果。若其中一方或双方是字符串，则进行字符串加法，整个运算符的结果是将右侧结果接在左侧结果之后所得的字符串。数值会被转换为字符串，对象类型若能转换为字符串则会被转换。
- **`-` 运算符**  
  `-` 运算符先对左侧求值，再对右侧求值。然后以数值方式用左侧结果减去右侧结果，其结果即为整个运算符的值。

## 乘除取余运算符

`**%**  **/**  **\**  *****` 分别是取余、除法、整数除法和乘法运算符。

- **`%` 运算符**  
  `%` 运算符先对左侧求值，再对右侧求值。然后用左侧除以右侧所得的余数即为整个运算符的值。两个值都被当作整数处理。
- **`/` 运算符**  
  `/` 运算符先对左侧求值，再对右侧求值。然后用左侧除以右侧所得的值即为整个运算符的值。值被当作实数处理。
- **`\` 运算符**  
  `\` 运算符像 / 运算符一样进行除法，但值被当作整数处理。
- **`*` 运算符**  
  `*` 运算符先对左侧求值，再对右侧求值。然后用左侧乘以右侧所得的值即为整个运算符的值。值被当作实数处理。

## 一般单目运算符类

以下全部是单目运算符 ( `instanceof` 例外 )。

- **`**!**` 运算符**  
  前置的 `!` 运算符是逻辑否定运算符。将右侧内容的求值结果的真伪反转后即为整个运算符的值。
- **`**~**` 运算符**  
  `~` 运算符是按位取反运算符。将右侧内容的求值结果作为整数，进行逐位取反 ( 1→0、0→1 ) 后即为整个运算符的值。
- **`**--**` 运算符**  
  前置的 `--` 运算符是前置**递减**运算符。将右侧内容减 1，减后的值即为整个运算符的值。
- **`**++**` 运算符**  
  前置的 `++` 运算符是前置**递增**运算符。将右侧内容加 1，加后的值即为整个运算符的值。
- **`**new**` 运算符**  
  `new` 运算符使写在右侧的函数求值表达式不进行函数调用，而是创建对象。
- **`**invalidate** 运算符`**  
  `invalidate` 运算符对右侧内容求值，并将求值结果的对象无效化。如果右侧内容是 void、字符串、数值、字节序列，则不做任何事。对象已经被无效化时也不做任何事。指定 null 时会发生异常。
- **`**isvalid** 运算符`**  
  `isvalid` 运算符对右侧或左侧内容求值，其求值结果的对象有效时为 true，无效时为 false。无论将运算符放在求值对象的前面还是后面，含义都相同。对象为 void、字符串、数值、字节序列时始终返回真。指定 null 时会发生异常。
- **`**delete** 运算符`**  
  `delete` 运算符删除写在右侧的对象成员或局部变量。删除成功时为 true，失败时为 false。
- **`**typeof** 运算符`**  
  `typeof` 运算符对右侧内容求值，根据其类型返回以下字符串 : void:"void"、整数:"Integer"、实数:"Real"、对象:"Object"、字符串:"String"、字节序列:"Octet" 。不过，指定了对象成员而该成员不存在时，结果为 "undefined"。
- **`**#** 运算符`**  
  `#` 运算符对右侧内容求值，将该字符串第一个字符的字符编码作为整个运算符的值。
- **`**$** 运算符`**  
  `$` 运算符对右侧内容求值，将其结果作为字符编码，该编码所表示的单个字符即为整个运算符的值。
- **`**+** 运算符`**  
  单目的 `**+**` 运算符对右侧内容求值。右侧内容是实数或整数时不做任何事。其他情况下会尝试转换为实数或数值，其结果即为整个运算符的结果。尝试将字符串转换为数值时，若转换失败，不会发生异常，而是变为 0。含有小数点的实数表示会转换为实数，否则转换为整数。字符串开头有 0x、0b 或 0 时，分别按十六进制、二进制、八进制解释。
- **`**-** 运算符`**  
  单目的 `-` 运算符对左侧内容求值，将其结果作为数值，正负反转后即为整个运算符的结果。
- **`**&** 运算符`**  
  单目的 `&` 运算符将写在右侧的对象成员的访问改为不经过属性处理器、而是对属性对象本身的访问。例如，propobj = &obj.prop; 中不会启动 obj 的成员属性 prop 的属性处理器，而是将对成员属性 prop 的**属性对象**本身的引用赋给 propobj。右侧不是对属性的访问时，行为未定义。
- **`***** 运算符`**  
  单目的 `*` 运算符使写在右侧的对象的属性处理器工作。右侧必须写表示属性对象的表达式。例如，*propobj = 1; 会调用属性对象 propobj 的 setter 处理器，赋值 1。
- **`**instanceof** 运算符`**  
  `instanceof` 运算符对左侧内容求值，接着对右侧内容求值。右侧写能作为类名的字符串，左侧内容是那个类的实例时为 true，否则为 false。

## 函数调用、括号类、后置递增、递减等

- **`**(  )** 运算符`**  
  `(  )` 运算符用于更改运算的优先级，或者进行函数调用。
- **`**[  ]** 运算符`**  
  `[  ]` 运算符是间接成员选择运算符。写成 `A [ B ]` 时，先对 A 求值，再对 B 求值。将 B 作为字符串，从 A 中查找该成员名，整个运算符即为对该成员的访问。作为左值使用时，还附带在对象内创建成员 B (若不存在则新建) 的作用。
- **`**.** 运算符`**  
  `.` 运算符是直接成员选择运算符。写成 `A.B` 时，对 A 求值。从 A 中查找 B，整个运算符即为对该成员的访问。作为左值使用时，还附带在对象内创建成员 B (若不存在则新建) 的作用。
  如果省略了 `.` 运算符的左侧，则在 with 语句外侧时引用 global 对象内的成员，在 with 语句内侧时引用该 with 所示对象的成员。
- **`**++** 运算符`**  
  后置的 `++` 运算符是后置递增运算符。将左侧内容加 1，作为整个运算符的值则是加 1 之前的左侧内容。
- **`**--** 运算符`**  
  后置的 `--` 运算符是后置递减运算符。将左侧内容减 1，作为整个运算符的值则是减 1 之前的左侧内容。
- **`**!** 运算符`**  
  后置的 `!` 运算符是表达式求值运算符。将左侧内容的求值结果作为字符串，并将其作为表达式字符串解释。结果就是解释并求值该表达式字符串所得的结果。表达式在 this 上下文 (使用该运算符的位置上的 this) 上运行。
- **`**incontextof** 运算符`**  
  `incontextof` 运算符先对左侧内容求值，再对右侧内容求值。将左侧内容的求值结果作为对象，把该对象的上下文部分替换为右侧内容的求值结果后即为整个运算的结果。
- **`**int** 运算符`**  
  int 运算符对右侧内容求值，将其转换为整数类型后即为整个运算符的结果。也可以像 C 语言强制类型转换那样写作 (int)。
- **`**real** 运算符`**  
  real 运算符对右侧内容求值，将其转换为实数类型后即为整个运算符的结果。也可以像 C 语言强制类型转换那样写作 (real)。
- **`**string** 运算符`**  
  string 运算符对右侧内容求值，将其转换为字符串类型后即为整个运算符的结果。也可以像 C 语言强制类型转换那样写作 (string)。
