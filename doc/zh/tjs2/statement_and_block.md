# 语句与块

## 语句与块

TJS2 的重大语法构成要素中有语句与块。

## 语句

语句以 **;** (分号) 结尾。既有直接在表达式后面加上分号的，也有在 if 等控制语法后面加上分号的。

```
	a++;
	func1();
	return a+b;
	などなど
```

## 块

块是把多个语句写在 **{ }** 之间归纳而成的。语句从上到下执行。

```
	{
		a++;
		b++;
	}

	{
		var t=func1();
		func2(t);
		break;
	}
```

块后面不需要 ; (分号)。



另外，所有块都会生成变量的**作用域**。

## 执行顺序

在 TJS 中，写在函数、类、属性以外部分的语句会随脚本的执行而执行。函数、类、属性中的语句在被调用之前不会执行。

```
	var a; // すぐに実行される

	function test()
	{
		a+=10; // 呼び出されるまで実行されない
	}

	a+=30; // すぐに実行される
```

更准确地说，类的定义、函数的定义、属性的定义会在脚本执行时首先被注册，之后，其他脚本要素从头开始执行。因此，函数、类、属性在同一脚本块内可以向后引用。

```
	test(); // この位置よりも後ろに宣言された関数でも、同じスクリプトブロック内ならば参照される

	function test()
	{
		inform("yah!");
	}
```

不同脚本块之间的函数等调用，在尝试进行函数调用时，只要作为目标的函数已处于被加载的状态，就可以进行。

另外，变量的声明按被加载的顺序依次处理，因此不能向后引用。

## 全局对象

全局对象是一种特殊的对象，它把全局位置 (广域位置) 中声明的变量、函数、属性等作为成员持有。可以通过 global 关键字访问。
