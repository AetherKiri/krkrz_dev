# 对字节序列的操作

## 对字节序列的操作

在 TJS2 中，字节序列名义上被当作 **Octet** 类的对象，但 Octet 类并不存在，实际上它也不是 Octet 类的对象 (不过对字节序列使用 typeof 运算符时会返回 "Octet")。

但是，将字节序列视为对象，就可以使用若干方法与属性。



与字节序列相关的实现尚未完成。

## length

length 属性返回字节序列的长度。请注意它不是方法而是属性。不过，不能向该属性赋值。

```
	var oct = <% 11 22 33 %>;
	var n = oct.length;  // n には 3 が代入される
	var n = <% 11 22 33 %>.length; // これも同じく 3 が代入される
```

## '数值' 属性

将数值作为属性间接指定时，可以访问该位置上的字节。

结果以字节的数值表示。

例如，设 oct 是表示字节序列的表达式，则 oct[0] 是表示开头字节的值的数值。

数值位置超出字节序列长度时，或者为负数时，会发生异常。



不能生成赋值表达式。

```
	var oct = <% 11 22 33 44 55 %>;
	var c = oct[0];  // 0x11 が c に代入される
	var c = oct[2];  // 0x22 が c に代入される
	oct[3] = 'A'; // 代入式は生成できないのでエラーになる
	var c = oct[100]; // 値が範囲外なのでエラーになる
```
