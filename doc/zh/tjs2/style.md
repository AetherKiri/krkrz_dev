# 风格等

## 风格等

TJS2 在风格上是继承了 C 语言流派的语言。与一句以换行结束的 BASIC 等不同，写法基本上是“自由格式”。



不过，不能像 JavaScript 那样用换行来结束一句。

## 自由格式

换行、空格、制表符等一般被称为“**空白字符**”的字符，只要不会使意思变得不明白，放在哪里都可以。另外，必须适当插入，以免意思变得不明白。

这些 (1) ~ (4) 全部含义相同。不过，从易读性的角度推荐 (2) 或 (3)。

(5) 是不加空格写成的，这样字符会连在一起，无法被正常解释。

(6) 在不应插入空格的地方插入了空格，因此会出错。

## 注释

被 `/*` 和 `*/` 包围的部分会被视为注释，不被解释。注释可以嵌套 ( 套叠 )。

同样，一行中 `//` 之后的部分也会被视为注释。

```
	function example(a,b,c)
	{
		return a*b/c; // a*b/c を返す
	}

	/*
		このようにコメントを書くこともできます
		/* コメントのネストは可能になっています */
	*/
```
