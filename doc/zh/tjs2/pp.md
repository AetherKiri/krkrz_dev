# 预处理器

## 预处理器

TJS2 可以处理**条件编译表达式** (与 C 的 #if 和 #endif 相对应)。它在脚本被实际解释之前处理，可以根据条件让脚本的某个部分不被解释，或让某个部分被解释。

条件编译表达式的风格与 C 的预处理器指令不同，是自由风格的，可以写在任何地方。并不像 C 的指令那样，必须在一行中只写一条指令。

## @set 指令

@set 指令对条件编译表达式求值，并丢弃结果。语法如下。

```
	@set(式)
```

“式”中写条件编译表达式。这里可以使用以下运算符。

```
	,  =  !=  ==  ||  &&  |  ^  &  <  >  <=  >=  +  -  %  *  /  !  +  -  ( )
```

关于这些运算符的含义，

请参阅。不过，可处理的数据类型仅为整数。

另外，可以使用任意变量、字面量。关于变量名的命名规则，

的变量命名规则及字面量适用相同的规则。

不过，预处理器中使用的变量与 TJS2 脚本中使用的变量不会相互干涉 (不共享同一命名空间)。

## @if 指令、@endif 指令

@if 指令对条件编译表达式求值，如果结果为 0，则到下一个 @endif 出现之前，其间的内容不会被解释。结果不为 0 时会被解释。

语法如下。

```
	@if(式)              ...         @endif
```

“式”中指定条件编译表达式。@if ~ @endif 可以嵌套。

```
	@if(flag==0)  // まだ何も代入されていない変数は 0 であると見なされる
		@set(flag=1)
		****
	@endif
	// ↑  **** の部分に書かれたスクリプトのコンパイルを一度きりのものとする

	@if(version>=0x02040009)
		@if(flag)
			****
		@endif
	@endif
	// ↑ version が 0x02040009 (2.4.9) 以上で flag が 0 以外の時のみ **** の部分をコンパイルする
```

## 预定义变量

**version** 变量表示当前 TJS2 的版本。



作为数值，是十六进制 0x0XYYZZZZ 的形式，X 的部分表示主版本号，YY 的部分表示次版本号，ZZZZ 表示发布编号。例如 0x02040009 的话，版本为 2.4.9。
