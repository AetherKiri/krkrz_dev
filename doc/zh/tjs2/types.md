# 数据类型

## 数据类型

TJS2 中的变量没有“类型”，但内部拥有类型。与其说没有类型，不如说类型是以自动/动态方式处理的。

内部类型包括 `void`、整数类型、实数类型、字符串类型、对象类型、字节序列类型。

## void

void 表示“不表示任何东西” (与 JavaScript 的含义不同)。刚声明的变量是 `void`。

`void` 之间的比较使用 `===` (识别) 运算符。

`**typeof**` 运算符对此返回 `"void"`。

## 整数类型

TJS2 可以将 64bit 精度的整数作为整数类型处理。整数通常被当作**有符号整数**处理，但唯一的例外是 `**>>>**` 运算符，它将左操作数当作**无符号整数**处理。

typeof 运算符对此返回 `"**Integer**"`。

## 实数类型

TJS2 可以将 64bit 精度的实数 (**双精度实数**) 作为实数类型处理。

typeof 运算符对此返回 `"**Real**"`。

## 字符串类型

TJS2 可以处理没有长度限制的、以零结尾的字符串。所谓以零结尾的字符串，是指假定字符串在 `\0` 处结束来加以处理。

内部字符编码为 **UTF-16LE**，每个字符固定以 16bit 保存。BMP 范围之外的字符用**代理对**表示。

typeof 运算符对此返回 `"**String**"`。

关于可用于字符串的方法与属性的列表，请参阅 [字符串](string.md)。

## 对象类型

对象类型是用于保持对象的类型。除用 `new` 运算符分配的对象之外，函数、类、属性对象等全部都会成为对象类型。

`typeof` 运算符对此返回 `"**Object**"`。



与 TJS 和 JavaScript 不同，TJS2 的对象类型在内部持有两个指针：指向对象本身的指针，以及指向其应被使用的上下文对象的指针，从而可以实现所谓的闭包。更改这个上下文部分的运算符就是 `incontextof` 运算符。

尤其是以下类在 TJS2 语法中拥有专用的字面量记法，会频繁出现。

- **数组** ( [Array 类](array.md) ) — 具有顺序的元素序列。在表达式中写 `[ ... ]` 即可当场生成。
- **字典数组** ( [Dictionary 类](dictionary.md) ) — 从字符串键到值的对应。在表达式中写 `%[ ... ]` 即可当场生成。
- **正则表达式模式** ( [RegExp 类](regexp.md) ) — 用于字符串匹配与替换的模式。可以以 `/.../` 的形式写成字面量。

## 字节序列类型

字节序列类型是处理 8bit 宽数据列 (字节序列类型) 的类型。主要是用于处理**二进制数据**的类型。

`typeof` 运算符对此返回 `"**Octet**"`。

关于可用于字节序列的方法与属性的列表，请参阅 [字节序列](octet.md)。
