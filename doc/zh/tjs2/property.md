# 属性

## 属性

属性可以像变量一样使用，但实际上与方法调用相同，会伴随**设置器** (**setter**) 和**获取器** (**getter**) 的调用。设置器和获取器有时也被称为属性处理器。



语法如下。

```
**property** 識別子
{
	setter(引数)
	{
		// ここにセッターの内容
	}

	getter()
	{
		// ここにゲッターの内容
		return 式; // ゲッターとして返す値
	}
}
```

setter 和 getter 以相反的顺序书写也没有关系。

该属性会作为定义此 property 的类、或全局的成员被注册，通过该标识符获取值会经由获取器，设置值会经由设置器。这些设置器和获取器可以像方法一样编写各种内容。设置器在 setter 之后的 ( ) 内，把接收值的变量作为参数书写。获取器通过 **return** 语句返回值。



getter 之后的 () 可以省略。



对一个标识符同时编写设置器和获取器，就成为可读写的属性。只编写其中一方时，例如只编写获取器时，就成为只读属性，写入会出错。

```
	var value;

	property property1 // プロパティ 'property1' を宣言
	{
		setter(v)
		{
			// セッターはただ一つだけの引数をとる
			value=v; // 引数 v を処理する

			inform("value set.");
		}

		getter
		{
			// propset と同じ識別子 'property1' のゲッターを宣言
			// ゲッターに引数はない
			inform("value get.");
			return value; // 戻り値として返す
		}
	}

	property1=5; // property1 への代入は、セッターが呼ばれる
	property1++; // このような式では、ゲッターが呼ばれ、
	             // 次にセッターが呼ばれて値が設定される
}
```

属性也和变量、函数、类一样，可以**重写**。

## 属性对象

属性本身也是一个对象。但是，当它被注册到某个对象上时，用普通的访问方式只会调用属性处理器，而无法访问属性对象本身。

要取出属性对象本身，使用 `**&**` 运算符。取出的属性对象可以放入局部变量。

另外，也可以使用 `&` 运算符注册属性对象。

```
	property prop // プロパティ prop を宣言
	{
		(略)
	}

{
	var p = &prop; // プロパティオブジェクトを得てローカル変数に入れる

	&object.property1 = p; // p を object の property1 として登録する
}
```

使用 `&` 运算符时，不会调用获取器和设置器，可以直接访问属性对象本身。不使用 `&` 运算符时，就是对普通属性的访问。



作为局部变量取出的属性对象，即使不注册到对象上，也可以使用 `*****` 运算符调用属性处理器。

```
	property prop // プロパティ prop を宣言
	{
		(略)
	}

{
	var p = &prop; // プロパティオブジェクトを得てローカル変数に入れる

	*p = 30; // setter を呼び出し 30 を設定する
	func(*p); // getter を呼び出し値を取得し、func に渡す
}
```

> **Note:**
> 如上所述，在把属性对象放进 var 变量时，请让变量成为局部变量。这是因为属性对象一旦被注册到对象上，就会不再作为属性对象、而是作为属性经由获取器和设置器来运行。也就是说，如果把它注册到不是局部变量的全局变量 (＝global 的成员) 或对象成员上，它就会像普通属性一样工作。当然，用 & 运算符取出这样注册到全局变量或对象成员上的属性对象，是没有问题的。

对属性对象配合 "Property" 使用 instanceof 运算符时为真 (就上面的例子而言，&prop instanceof "Property" 为真)。
