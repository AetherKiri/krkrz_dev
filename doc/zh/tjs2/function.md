# 函数

## 函数

TJS2 的函数与**子例程**几乎同义。不返回值的情况也作为函数处理。

另外，特别是作为类或对象成员存在的函数，有时会称为“**方法**”。

## 函数的写法

函数可以按以下格式书写。

```
	function 関数名 ( 引数リスト )
	{
		関数の内容
	}
```

首先，要定义函数，需写上 **function**。然后在后面写上函数的名称。用这里写下的名称即可使用该函数。

在函数内容中，可以记述希望在函数内执行的语句或块。

```
	function test(a) { System.inform(a); }
	function func(a, b, c, d)
	{
		test(a);
		test(b);
		test(c);
		test(d);
		return a+b-c*d;
	}
```

对函数使用带有 "Function" 的 instanceof 运算符时，结果为真 (就上面的例子而言，func instanceof "Function" 为真)。

## 函数的调用

函数的调用使用 **( )** 运算符，按以下方式记述。

`
函数名( 参数 )

`
没有参数时，则为 `関数名( )`。参数中指定表达式，有多个时用逗号分隔指定。

```
	func();
	func(1+2, 1-2);
	func(func2());
```

另外，如果不指定表达式而留空，则该部分会被视为指定了 void。

```
	func(,1); // void, 1 が指定されたとみなされる
	func(,); // void, void が指定されたと見なされる
```

## 参数列表

在参数列表中，写上用于接收所传递参数的变量名。函数调用时传递的参数中，从前面写起的参数会按顺序传递给变量。

```
	function test(a, b, c)
	{
		// この時点で、 a と b と c という変数が使用可能であり、
		// 引数として渡された 3 つの引数が代入されています。
		// test(1, 2, 3) と呼び出した場合は、 a に 1、
		// b に 2, c に 3 が入っています。
	}
```

这些参数是局部变量，一旦执行从函数中退出，就无法再访问。



在 TJS2 中，函数调用时给出的参数即使比声明的参数个数少或多，也不会出错 (作为例外，并非用 TJS2 记述的函数 (实体用 C++ 等记述的函数) 有时会报错)。给出的参数比声明多时，多出的部分会被忽略；少时，不足的变量会被传入 void。

```
	function test(a, b)
	{
		// もし test(1) として呼び出すと、a には 1 、b には void が入る。
		// もし test(1,2,3) として呼び出すと、 a には 1、 b には 2 が入り、3 は無視される
	}
```

参数列表中的各个参数都可以在 = 之后指定默认值 (**默认参数**)。这是指在指定了 void 时，或者给出的参数不满足声明的参数时，会自动使用所指定的值。

```
	function test(a = -1, b = 1)
	{
		// もし・・・
		// test() として呼び出すと、 a=-1, b=1
		// test(5) として呼び出すと、 a=5, b=1
		// test(void,void) として呼び出すと、 a=-1, b=1
		// test(,4) として呼び出すと、a=-1, b=4
	}
```

不需要接收参数的函数可以省略参数列表。

```
	function test
	{
		// 引数を受け取らない関数
	}
```

## 函数表达式

在表达式内使用 function 关键字，可以创建没有名称的函数，即函数表达式 (**匿名函数**)。

这种情况下，省略函数名。

```
	var func = function(i) { return i*5; };
	var func2 = function { System.inform("hoge"); };
	var v = func(); // func 呼び出し
	func2(); // func2 呼び出し
```

## 参数的省略

调用函数时，如果只把 **...** 作为参数写出，则书写了该调用表达式的函数所接收到的参数，会被原样传递给被调用的函数。这样，即使更改了参数变量的内容，或者收到的参数不足，传递的也是正确的原始内容与参数个数。

```
	function test()
	{
		test2(...);
		// test2 には test に渡された引数が、渡された時点のまま
		// の内容、個数で渡される
	}
```

## 参数转换为数组

可以将参数作为数组接收。要作为数组接收，需在参数名后加上 '*****' 来声明函数。

```
	function func(args*)
	{
		// args はこの関数に渡された引数を要素として持つ配列になる
		// たとえば func(1, 2, 3, 4) として呼び出された場合、
		// args には 4 つの要素が入っており、先頭から 1 2 3 4 の順で
		// 数値が入っていることになる。
	}
```

也可以从参数的中间到末尾全部作为数组接收。参数个数不足时，数组将为空。

```
	function func(x, args*)
	{
		// たとえば func(1, 2, 3, 4) として呼び出された場合、
		// x には 1 が入る。また args には 3 つの要素が入っており、
		// 先頭から 2 3 4 の順で数値が入っていることになる。
		// func(1) として呼び出された場合、引数の数が満たないため、
		// args は要素のない配列となる。
	}
```

这在希望处理可变长参数时很方便。



也可以不指定参数名。这种情况下，在后述的将数组展开为参数时，可以作为没有名称的 * 使用。

## 将数组展开为参数

可以将数组展开，并作为参数传递给函数。这种情况下，与参数的数组展开时相同，在希望展开的表达式后面加上 '*****' 来调用函数。指定 '*' 来展开的表达式必须是表示数组的表达式。

```
	var args = [1, 2, 3, 4];
	func(args*);
	// args には 1 2 3 4 の4つの要素が入っているため、
	// func(1, 2, 3, 4); と同じ意味になる。
	func(0, args*, 5);
	// このように引数の途中に挟むことも可能。
	// この場合は、func(0, 1, 2, 3, 4, 5); と同じ意味に
	// なる。
```

不指定表达式，而只是将 * 指定为参数时，可以将书写了该调用表达式的函数在声明时所写下的、没有名称的 '*' 所表示的参数，原样传递给调用目标。

```
	function func(func_array, *)
	{
		// func_array で指定された関数に、
		// その関数の func_array 内の位置につづき、
		// func に渡された 2 番目以降の引数を
		// そのまま引き渡して呼び出す
		for(var i = 0; i < func_array.count; i++)
			func_array[i](i, *);
	}
```

使用没有名称的 * 进行的函数调用处理，比使用有名称的数组更高效。

```
	function func(ar*) { func2(ar*); }
	function func(*) { func2(*); }
	// 上記の二つは全く同じ意味になるが、下の例の方が効率がよい
```

没有名称的 * 具有与“参数的省略”相同的效果。以下两个函数声明含义相同。

```
	function func() { func2(...); }
	function func(*) { func2(*); }
```
