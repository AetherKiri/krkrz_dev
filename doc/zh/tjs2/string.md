# 对字符串的操作

## 对字符串的操作

在 TJS2 中，字符串名义上被当作 **String** 类的对象，但 String 类并不存在，实际上它也不是 String 类的对象 (不过对字符串使用 typeof 运算符时会返回 "String")。

但是，将字符串视为对象，就可以使用若干方法与属性。

## length

length 属性返回字符串的长度。请注意它不是方法而是属性。不过，不能向该属性赋值。



TJS 在内部将所有字符都以 **UNICODE** 处理，因此全角字符也计为 1 个字符，半角字符也计为 1 个字符。

```
	var str = "abc漢字";
	var n = str.length;  // n には 5 が代入される
	var n = "abc漢字".length; // これも同じく 5 が代入される
```

## '数值' 属性

将数值作为属性间接指定时，可以访问该位置上的字符。

例如，设 str 是字符串或者表示字符串的表达式，则 str[0] 是表示开头一个字符的字符串。

数值位置超出字符串长度时，或者为负数时，会发生异常 (不过字符串末尾的位置会返回空字符)。



不能生成赋值表达式。

```
	var str = "abcdef";
	var c = str[0];  // 'a' が c に代入される
	var c = str[2];  // 'c' が c に代入される
	str[3] = 'A'; // 代入式は生成できないのでエラーになる
	var c = str[100]; // c 値が範囲外なのでエラーになる
	var c = str[6]; // 空文字 '' が代入される
```

## charAt

charAt 方法返回字符串中指定位置的字符。其运行方式与 '数值' 属性相同，但超出范围时总是返回空字符串 (不会抛出异常)。

```
構文 : charAt(<文字位置>)
```

```
	var str = "abcdef";
	var c = str.charAt(3); // 'd' が c に代入される
```

## indexOf

indexOf 方法返回子字符串的位置。

```
構文 : indexOf(<部分文字列>[,<検索開始位置>])
```

从字符串中，从<搜索开始位置>开始搜索<子字符串>，返回最初找到的位置。如果返回 0，则表示字符串的开头。返回 -1 时表示没有找到。省略<搜索开始位置>时，则从字符串的开头开始搜索。

```
	var str = "abcdefghijkl";
	var n = str.indexOf("fgh"); // n には 5 が代入される
	var n = str.indexOf("xyz"); // n には -1 が代入される
```

## toLowerCase

此方法没有参数。

toLowerCase 返回将字符串中的字母转换为小写的字符串。

全角字符不会被转换。



这些方法不会影响原字符串。

```
	var lwr="ABCDEF".toLowerCase(); // lwr には "abcdef" が代入される
```

> **Note:**
> 当前版本的 TJS2 仅对字符编码小于 0x80 的字符进行转换。

## toUpperCase

此方法与 toLowerCase 相反，返回将小写字母转换为大写的字符串。

## substring

substring 方法返回字符串的子字符串。

```
構文 : substring(<開始文字位置>[,<文字数>])
```

返回字符串中从<开始字符位置>起<字符数>个字符的子字符串。不会影响原字符串。省略<字符数>时，将返回<开始字符位置>之后的全部字符串。

请注意它与 JavaScript 的同一方法在参数含义上有所不同。

```
	var ss="abcdefghijkl".substring(3,3); // ss には "def" が代入される
```

## substr

与 substring 相同。

## sprintf

sprintf 方法格式化字符串。

```
構文 : sprintf(引数, 引数, ....)
```

将该字符串视为格式字符串，返回进行与 C 语言中 sprintf 相同的文本格式化后的字符串。不会影响原字符串。

```
	var formatted = "%04X %c %5d".sprintf(v1, v2, dic[v1]);
```

## replace

replace 方法进行字符串的替换。

```
構文 : replace(<パターン>, <置き換え後文字列>)
```

按照正则表达式模式进行字符串替换，返回替换后的字符串。不会影响原字符串。

## split

split 方法分割字符串。

```
構文 : split(<パターン/デリミタ集合>, <(予約)>, <空の要素を無視するか=false>)
```

返回保存了字符串分割结果的数组对象。

的 split 方法也请参照 (请注意参数的顺序)。

## escape

escape 方法将字符串转换为可在 TJS 的字符串字面量内表示的形式。\ 和 " 等符号都会改用 \ 符号处理，从而不再被解释为特殊用途 (被转义)。

```
構文 : escape()
```

返回转义后的字符串。不会影响原字符串。

```
	var escaped = str.escape(); // str 中の " は \" に、\ は \\ に変換されるなど
```

## trim

trim 方法返回去除了字符串开头和末尾空白后的字符串。不会影响原字符串。

开头和末尾的空白指的是字符编码为 U+0001~U+0020 的字符。也就是说，虽然也包括 ASCII 控制字符等，但不包括所谓的全角空白。

如果开头或末尾连续存在这些空白，则会全部被去除。

```
構文 : trim()
```

返回删除了开头和末尾空白字符的字符串。不会影响原字符串。

```
	var str = "  Hoge ".trim(); // str は "Hoge" です。
```

## reverse

reverse 方法返回将字符顺序颠倒后的字符串。不会影响原字符串。

当前版本的 TJS2 不保证 UTF-16 中包含代理对的字符串的行为。

```
構文 : reverse()
```

返回将字符顺序颠倒后的字符串。不会影响原字符串。

```
	var str = "Hoge".reverse(); // str は "egoH" です。
```

## repeat

repeat 方法返回将字符串重复指定次数后的字符串。不会影响原字符串。

```
構文 : repeat(count)
```

返回将该字符串重复 count 次的字符串。不会影响原字符串。

```
	var str = "Hoge".repeat(3); // str は "HogeHogeHoge" です。
```
